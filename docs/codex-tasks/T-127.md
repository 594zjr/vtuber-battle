# T-127 多局制接入淘汰赛和加赛

依赖：T-54、T-118（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
T-54（三局两胜等多局制）合并后，让淘汰赛的每一场可以设为多局制，决胜局平局时按 T-118 的规则自动加赛。

## 要做的
1. 淘汰赛和循环赛的每场可选用 T-54 的赛制配置；多局制下按局累计，先赢够局数的晋级。
2. 一局平局不算任何一方赢；如果打完规定局数仍未分出胜负，按 T-118 的派生种子规则加赛（最多 3 次，仍平则种子顺位高者晋级）。
3. 战报（T-110）、存档续赛、禁用（T-121，如已合并）都按局记录。
4. 不改 T-54 自身的多局规则。

## 验收
自带测试 `Engine.Tests/T127_EliminationBestOfTests.cs`：三局两胜 2:0、2:1 晋级正确；含平局时补足局数；最终仍平时自动加赛；中途存档续赛结果与不中断一致；战报按局列出。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
