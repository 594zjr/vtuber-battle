# T-63 局域网房间发现

依赖：T-31（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
同一个局域网里，一方开房，另一方不用输 IP 就能在列表里看到并加入。

## 要做的
1. 新文件 `Core/Net/LanDiscovery.cs`：
   - `public sealed class LanRoom { public string Name, Address, ContentHash, Ruleset; public int Port, Protocol; public double LastSeen; }`
   - `public static class LanBeacon { public const int Port = 47777; public static string Encode(LanRoom r); public static LanRoom Decode(string text); }`：JSON，带魔数 `"magic":"SD-LAN-1"`；魔数不对、字段缺失、端口不在 1～65535、长度超过 512 字节都返回 null（不抛异常）。房名最长 24 个字符，超长截断。
   - `public sealed class LanRoomList { public void Receive(string text, string fromAddress, double now); public List<LanRoom> Rooms(double now); }`：同地址同端口的房间更新而不是重复；超过 3 秒没收到广播的房间从列表里去掉；`Address` 用收到包的来源地址，不信任包里自己写的地址。
   - 真正收发 UDP 的 `LanBeaconSender`、`LanBeaconListener`（`System.Net.Sockets.UdpClient`，每秒广播一次；监听端口被占用时给出中文错误而不是崩溃）。测试只测上面三个纯逻辑类。
2. `Tools/Cli` 加 `--lan-host <房名>`（开房并广播）和 `--lan-list`（列出 5 秒内看到的房间）。

## 不要做
- 不做公网匹配、服务器、NAT 穿透。
