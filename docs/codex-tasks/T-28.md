# T-28 命令行：回看、禁用、首发、档案一体化

依赖：T-17、T-23、T-25、T-26（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
命令行版成为不用 Unity 的完整玩法入口。

## 要做的
1. `Tools/Cli`：
   - 每局结束自动把 `Battle.Record.ToJson()` 存到 `--save-dir/replays/<时间>_<packId>.json`（最多 50 个）。
   - `--replay <文件>`：重放并逐回合打印（回车下一回合，`q` 退出；`--auto` 时一次打完）。
   - `--ban`、`--lead` 同时开启时按“禁用 → 首发 → 对战”的顺序交互。
   - 结束后打印 `BattleSummary.ToText()` 和档案里本包战绩。
   - `--help` 列出所有参数的中文说明。
2. 在 `Engine.Tests` 加一个测试：用 `--auto --seed 1 --ban --lead` 的同等 API 调用跑一局，存档后 `--replay` 等价的 `Replay.Run` 得到相同日志。
3. README 的命令行一节更新。

## 验收
`dotnet run --project Tools/Cli -- --auto --seed 1 --ban --lead` 两次输出完全一致；`--replay` 能播放刚存的文件。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
