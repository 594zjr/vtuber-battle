# T-05 给界面用的预览：伤害范围和先手预测

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
界面上悬停技能时显示“预计伤害 x～y”和“这回合谁先手”，需要引擎提供**不消耗随机数**的预览接口。

## 要做的
在新文件 `Core/Preview.cs`（`public sealed partial class Battle`）里加：
1. `public sealed class DamagePreview { public int Min, Max; public double Eff; public List<string> Notes; }`
2. `public DamagePreview PreviewDamage(int side, int skillIndex)`：用当前状态计算该技能打对面场上主播的伤害范围。命中前的威力倍率（`POWER_MUL` 按“本方先手”的假设判断条件、`POWER_PER_MARK` 按当前层数）要算进去；Min 对应随机系数 0.85，Max 对应 1.0；不含暴击；状态技能返回 0、0。**绝不能调用 Rng**。可以给现有的 `CalcDamage` 加一个参数来指定随机系数，但不要改变它现有调用的行为。
3. `public sealed class OrderPreview { public int First; public string Reason; }` 和 `public OrderPreview PreviewOrder(BattleAction a0, BattleAction a1)`：按 docs/design.md 3.3 节预测先手方。First 为 0 或 1；先制和反应都相同时 First = -1，Reason 写“随机”。只有一方行动（另一方换人）时，行动的那一方就是先手。Reason 的写法和日志里一样，例如“先制 3 对 0”“先制都是 0，反应 360 对 300”。同样不能调用 Rng。
