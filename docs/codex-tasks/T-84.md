# T-84 画面数据差量（只刷新变化的部分）

依赖：T-41（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战界面每回合只更新变化的部分，减少卡顿，也方便做「数值变化」提示。

## 要做的
1. 新文件 `Core/View/ViewDiff.cs`：`public static List<ViewChange> Between(BattleViewModel before, BattleViewModel after)`；`ViewChange { string Path; string Kind /* set|add|remove */; string Old, New; }`。Path 例如 `sides/0/team/2/hp`、`sides/1/team/0/statuses/stall`、`skills/3/pp`、`phase`、`notice`。
2. 覆盖 `BattleViewModel` 的全部字段（新增字段时测试要能发现遗漏：用反射列出所有公开字段并检查每个都能产生差量）。
3. `before` 为 null 时返回全部字段的 `set`。
4. 性能：一回合的差量计算在 `Tools/Bench`（T-52）里加一项，记录平均耗时。

## 验收
自带测试 `Engine.Tests/T84_ViewDiffTests.cs`：相同视图差量为空；打一回合后人气、PP、状态的变化都被列出且旧值新值正确；把差量依次应用到旧视图的序列化结果上能得到新视图的序列化结果；反射检查没有遗漏字段。
