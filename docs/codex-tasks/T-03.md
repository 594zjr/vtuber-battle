# T-03 新效果代码：PP_REDUCE 和 FIXED_DAMAGE

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
加两个新的技能效果代码。规则见 docs/design.md 第 3.4、5、6.1 节。

## 要做的
1. `Core/Battle.cs` 的 `Fighter` 增加 `public int LastSkillIndex = -1;`：每次真正用出一个技能（扣 PP 之后、命中判定之前）记下它的下标；“硬撑”不算；被控制跳过不算；下场时重置为 -1。
2. 在 `RunEffect` 的效果分派里加：
   - `PP_REDUCE`（参数 `n`、`target`）：目标 `LastSkillIndex` 指向的技能 PP 减 n，不低于 0，日志写“X 的「技能名」PP -n”。目标还没用过技能时日志写“X 还没有用过技能，PP 削减无效”（测试会查找“还没有用过技能”这几个字）。
   - `FIXED_DAMAGE`（参数 `n`、`target`）：对目标造成正好 n 点伤害（人气不足时扣到 0），不受能力等级、赛道、直播间效果、人设、暴击影响。它算“受到伤害”（会让挂机状态解除，可以让目标下播），但不触发“被击中后”类人设。
3. `Core/Describe.cs`：两个新代码的说明文字，例如“对手最后使用的技能 PP -3”“造成固定 77 点伤害”。
4. `docs/design.md` 6.1 节的效果码表加两行。
5. `Core/Content.cs` 的读取已经支持 `n` 字段，不用改；如果你发现不支持就补上。
