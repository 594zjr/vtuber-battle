# T-60 动画时间线：把战斗事件排成动画提示

依赖：T-40（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
画面动画只按一张「时间线」播放，时间线由纯 C# 从 `Battle.Events` 生成，可以用 dotnet 测试。以后换美术、换 Live2D 都不用改这里。

## 要做的
1. 新文件 `Core/View/BattleTimeline.cs`：
   - `public enum CueKind { Enter, SwitchOut, SwitchIn, Cast, Projectile, Hit, Flash, FloatText, HpBar, Faint, StatusIcon, FieldBanner, Miss, End }`
   - `public sealed class AnimCue { public double Start, Duration; public CueKind Kind; public int EventIndex, LogIndex, Side, Slot, Amount; public string Id, Text, Style; }`（Style 是跳字样式：`damage`、`heal`、`crit`、`miss`、`stage-up`、`stage-down`、`status`）
   - `public static List<AnimCue> Build(IReadOnlyList<BattleEvent> events, int from, int to, double speed = 1.0)`：处理 `events[from..to)`。
   - `public static double TotalDuration(IList<AnimCue> cues)`。
2. 生成规则（1 倍速的时长，单位秒；写进 `docs/design.md` 新的小节「画面动画时间线」）：
   - Act → Cast(0.35，施放方) 接 Projectile(0.25，Side 为施放方，Id 为技能 id)；Damage → 同一时刻 Hit(0.2) + Flash(0.12) + FloatText(0.8，文字 `-数值`，Style `damage`) + HpBar(0.4)；Crit → FloatText「暴击」(Style `crit`)，和紧随的 Damage 同时开始；Miss → Miss(0.3) + FloatText「未命中」；Heal → FloatText `+数值`(Style `heal`) + HpBar；Faint → Faint(0.5)；Switch → SwitchOut(0.3) 接 SwitchIn(0.35)；Enter → Enter(0.4)；StatusAdd/StatusRemove → StatusIcon(0.3，Amount 为剩余回合，移除时 Amount=0)；FieldAdd/FieldRemove → FieldBanner(0.6)；StageChange → FloatText `攻击 +1` 之类（能力名用 `Loc`，Style `stage-up`/`stage-down`）；End → End(0)。PpChange、Info 不生成提示。
   - 同一事件生成的提示共用 EventIndex；下一事件在上一事件最长的提示结束后开始（Crit 与紧随的 Damage 例外，同时开始）。
   - `speed` 为倍速：所有 Start 和 Duration 除以 speed；`speed <= 0` 表示跳过动画，全部 Start=0、Duration=0（提示仍然生成，画面直接显示终态）。
   - 不读系统时间、不用随机数；同样的输入永远得到同样的输出。
3. 文字一律走 `Loc`（T-42），新增的文本键加到 `Resources/Locale/zh-CN.json`。
