# T-97 玩家名字与文字输入的过滤

依赖：T-82（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
玩家可以输入的文字（昵称、队伍预设名、房间名、录像备注）统一过滤，避免乱码、超长和不当内容出现在别人屏幕上。

## 要做的
1. 新文件 `Core/TextInput.cs`：`public static TextInputResult Clean(string raw, TextInputKind kind)`；Kind：`PlayerName`（≤ 12 字）、`TeamName`（≤ 16）、`RoomName`（≤ 24）、`Note`（≤ 60）。结果含清理后的文字和中文提示（为什么被改）。
2. 规则：去掉控制字符、零宽字符、换行；连续空白合并；全角半角空格统一；超长截断；为空时用默认值（例如「玩家」「我的队伍」）；命中 T-82 的禁用词表（`Resources/Lint/banned.txt`）时用「*」替换该词并提示。
3. 收到对方发来的名字（联网、观战、录像、队伍码）时同样过滤后再显示。
4. 在 `NetSession`、`LanBeacon`（如果已合并）、`TeamPreset`、`ReplayLibrary` 等接收或保存文字的地方接入。

## 验收
自带测试 `Engine.Tests/T97_TextInputTests.cs`：控制字符和零宽字符被去掉；超长被截断到上限；空名字给默认值；禁用词被替换且有提示；联网时对方发来的超长名字在本机显示为清理后的版本；正常中文、英文、数字、常见符号不被改动。
