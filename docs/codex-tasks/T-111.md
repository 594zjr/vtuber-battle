# T-111 同屏对战的选招限时与超时默认行动

依赖：T-86（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
同屏双人对战（T-86）目前可以无限思考。加一个可选的每回合限时，超时自动选一个默认行动，而且结果确定、可回放。

## 要做的
1. `HotseatSession`（或其选项类）增加 `TurnTimeLimitSeconds`（0 = 不限时，默认 0；可选 10、20、30、60）。
2. 计时不读系统时间：由调用方每帧传入经过的时间（`Tick(double dt)`），便于测试和以后接 Unity。
3. 超时默认行动：上一回合同一技能仍可用就用它；否则选第一个可用技能；都不可用时按引擎现有的「挣扎/无行动」规则。被控制时不额外处理（与引擎一致）。超时行动写进录像，回放结果与正常选招一致。
4. 私密选招流程不变：超时只替当前轮到的一方选择，不泄露对方的选择。
5. `Tools/Cli` 同屏模式加 `--turn-limit <秒>`；超时时打印中文提示「超时，已自动选择 xxx」。

## 验收
自带测试 `Engine.Tests/T111_HotseatTimerTests.cs`：限时 0 时永不超时；超时选择符合上述三条优先级；只给一方超时时另一方的选择不受影响；含超时行动的录像回放 `StateHash` 一致；`Tick` 分多次累计与一次性传入结果相同。
