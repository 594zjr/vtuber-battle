# T-79 联网协议文档与兼容性测试

依赖：T-29、T-32（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
把联网对战的消息格式写成文档，并用「固定样例消息」测试锁住格式，避免以后改代码时无意中破坏和旧版本的兼容。

## 要做的
1. 新文件 `docs/netplay-protocol.md`：握手、承诺、揭示、补位、哈希校验、结束、错误等每种消息的字段、类型、发送时机、错误处理；协议版本号规则（什么时候必须加 1）。
2. 新目录 `Engine.Tests/Golden/net/`：每种消息至少一个样例 JSON 文件（由当前代码生成后固定）。
3. 自带测试 `Engine.Tests/T79_NetProtocolGoldenTests.cs`：当前代码生成的消息与样例逐字段一致；样例消息能被当前代码正确解析；多余未知字段被忽略而不是报错；缺少必需字段时进入 `Error` 并给出中文原因。
4. 如果发现当前实现与文档不一致的地方，以代码现状为准写文档，并在 PR 的「需要决定」里列出觉得不合理的点（不要顺手改协议）。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
