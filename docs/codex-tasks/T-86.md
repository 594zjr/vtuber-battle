# T-86 同屏双人对战流程（一台电脑两个玩家）

依赖：T-25（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
两个人用同一台电脑对战：轮流出招时看不到对方选了什么。

## 要做的
1. 新文件 `Core/HotseatSession.cs`（纯逻辑）：`HotseatSession(ContentDb db, IList<string> teamA, IList<string> teamB, string nameA, string nameB, BattleOptions opt)`。
   - `int WhoseTurn`（0/1/-1：-1 表示正在结算或已结束）、`bool NeedsHandover`（交给下一位玩家前需要「请把电脑交给对方」的遮挡画面）、`void ConfirmHandover()`。
   - `void Submit(BattleAction a)`、`void SubmitReplace(int to)`、`void SubmitBan(int idx)`、`void SubmitLead(int idx)`：按当前玩家提交；双方都提交后结算。先提交的一方的选择在另一方提交前不能通过任何公开属性读到（视图数据 `ViewFor(side)` 不包含对方本回合的选择）。
   - `BattleViewModel ViewFor(int side)`：只显示该玩家应该看到的内容。
2. 首发选择、禁用、补位（只有一方需要补位时不需要交接）都正确处理。
3. 录像（`BattleRecord`）与普通对战一致，可以 `Replay.Run` 重放。
4. `Tools/Cli` 加 `--hotseat`（每次交接时清屏并提示）。

## 验收
自带测试 `Engine.Tests/T86_HotseatTests.cs`：双方轮流用电脑选择打完整局，结果与同样行动直接调用 `Battle` 一致；先提交方的选择在对方提交前不出现在 `ViewFor(对方)`；只有一方补位时不需要交接；录像可重放。
