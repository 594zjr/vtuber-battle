# T-98 投降与提议和局

依赖：T-29（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战中可以认输，联网对战还可以向对方提议和局。

## 要做的
1. 新行动 `ActionType.Surrender`（`BattleAction.Surrender()`）：任何选择阶段（出招、补位、首发、禁用、选人）都可以提交；结算时投降方立即判负（双方同回合都投降判平局），写日志和 `BattleEvent.End`。
2. 联网：`NetSession.OfferDraw()`、`RespondDraw(bool accept)`、`DrawOffered`（对方提议待回应）；同意则判平局；每方每 5 回合最多提议一次；拒绝不影响对战。提议和回应进录像，重放结果一致。
3. 排位（T-57）：投降算负；和局按平局计算。
4. 电脑：不会主动投降；对方提议和局时，自己人气总和占优超过 30% 拒绝，否则同意（规则写进 design.md）。
5. `Tools/Cli` 加 `/surrender`、`/draw` 指令。

## 验收
自带测试 `Engine.Tests/T98_SurrenderDrawTests.cs`：任一阶段投降立即结束且胜方正确；双方同回合投降为平局；联网提议和局被接受/拒绝两种情况双方状态一致；限频生效；录像重放结果一致；`StateHash` 双方一致。
