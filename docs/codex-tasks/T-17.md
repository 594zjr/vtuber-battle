# T-17 命令行对战

依赖：T-06（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
不开 Unity 也能完整玩一局，方便测试和调规则。

## 要做的
1. 新命令行工程 `Tools/Cli/Cli.csproj`（net8.0，引用 Engine）。`dotnet run --project Tools/Cli -- --pack fan_asoul_vr --level normal [--seed 1] [--team id1,id2,...]`。
2. 控制台中文界面：显示双方场上主播、人气、状态和直播间效果；列出 5 个技能（PP、先制、〔命中前/命中后〕效果说明）和可换的队友；输入数字选择。每回合把本回合新增的 `Battle.Log` 按节点分组打印。
3. `--auto` 参数：双方都由电脑操作，直接打印整局，用于快速看日志。
4. README 加一行用法。

## 验收
`--auto --seed 1` 两次输出完全一致；手动打完一局没有异常。
