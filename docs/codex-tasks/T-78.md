# T-78 电脑陪练对手名单

依赖：T-39（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
「对电脑」时可以挑一个有名字、有固定阵容和难度的电脑对手，而不只是随机阵容。（这是对战模式里的对手选择，不是闯关或进度。）

## 要做的
1. 新文件 `Core/AiOpponents.cs`：`public sealed class AiOpponent { string Id, Name, Blurb, PackId; List<string> Team; AiLevel Level; string Style; }`；`public static List<AiOpponent> For(ContentDb db)`。
2. 每个内容包至少 6 个对手，难度从 Easy 到 Expert 都有；阵容来自该包主播（可用 `TeamBuilder.Suggest` 生成后固定写死，保证换版本也不变），必须通过 `TeamCheck`。对手名字和简介原创（例如「新人练习生」「深夜连麦王」），同人包的对手名不得冒充真实主播本人（不要写成「某某本人」），只描述阵容风格。
3. 如果 T-53 已合并，`Style` 用它的出招风格；否则留 null 并在 PR 里说明。
4. 数据放在新文件 `Resources/AiOpponents.json`（按包 id 分组），代码只负责读取和校验；`ContentDb` 不变。
5. `Tools/Cli` 加 `--vs <对手id>`。

## 验收
自带测试 `Engine.Tests/T78_AiOpponentsTests.cs`：每个包至少 6 个对手、四个难度都有；所有阵容合法；id 不重复；用每个对手打一局都能正常结束。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
