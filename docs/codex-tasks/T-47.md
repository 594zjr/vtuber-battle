# T-47 教学关卡（规则层）

依赖：T-46（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
新手教学：一步一步引导玩家出招，出错就提示。这次做规则和脚本，Unity 画面以后接。

## 要做的
1. 新文件 `Core/Tutorial.cs`：
   - `public sealed class TutorialLesson { public string Id, Title; ... }`；`public static List<TutorialLesson> Tutorial.Lessons(ContentDb db)`：至少 4 课：基本出招、赛道克制、状态与驱散（消回合 / 消强化 / 净化的区别）、换人与补位。用原创包的主播。
   - `public sealed class TutorialRunner`：构造 `(ContentDb db, TutorialLesson lesson)`；属性 `Battle`、`Done`、`CurrentHint`（中文提示，说明这一步要做什么、为什么）、`Expected`（本步期望的 `BattleAction`）；`Submit(BattleAction a)` 返回 `TutorialResult { bool Accepted; string Message; }`：不符合期望时不结算、`Message` 解释为什么不对；符合时按脚本让电脑出预定的行动并结算。
   - 每课固定种子、固定双方行动，结果完全可复现；课程里的数值可以用修饰器（T-46）或直接设定人气，保证几步之内讲清一个知识点。
2. 提示文案：短句、口语化、讲规则不讲剧情。**文案禁区**：全部原创中文；不得出现赛尔号（淘米）的任何名字或文本；不写现实事件、真人隐私、擦边、贬损、政治宗教内容；涉及同人包主播时只用公开艺名和公开、正面的人设。
3. `Tools/Cli` 加 `--tutorial [课号]`。
