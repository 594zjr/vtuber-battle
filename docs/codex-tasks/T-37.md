# T-37 可读战报导出

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
一局打完可以导出一份 Markdown 战报，方便贴到论坛或发给朋友。

## 要做的
1. 新文件 `Core/BattleReport.cs`：`public static string Markdown(Battle b)`。
   - 开头：内容包名、双方名字和首发阵容、胜负（平局写“平局”）；同人包要原样带上内容包的 `notice`。
   - 正文按回合分节，标题 `## 第 N 回合`；每节里按节点（开场/换人/回合开始/先手行动/后手行动/回合结束/补位/结束）分组列出日志原文，**日志一行不漏、顺序不变**。
   - 结尾：如果 `BattleSummary` 存在（T-23 已合并），附上统计表。
2. `Tools/Cli` 加 `--report <文件>`：对局结束（或 `--replay` 播放完）后写出战报。
3. 只做 Markdown，不做 HTML。

## 验收测试
把 `Engine.Tests/Pending/T37_ReplayReportTests.cs` 移到 `Engine.Tests/`，让它通过。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
