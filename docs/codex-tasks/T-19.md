# T-19 内容包可以自带技能、人设、效果和状态

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
做同人包时，每位主播可以有自己独有的招牌技能和人设，而不用改共用的 `StreamDuelRules.json`。

## 要做的
1. 内容包 JSON 可以有可选的 `skills`、`personas`、`fields`、`statuses` 四个对象，格式与 `StreamDuelRules.json` 里同名对象完全一样。读取时合并进这个包自己的 `ContentDb`。
2. id 与规则文件里已有的 id 重复时抛 `KeyError`，信息里写出重复的 id 和类别；包里的定义只存在于这个包的 `ContentDb`，不影响别的包。
3. 合并后再做全部校验（引用的赛道/状态/效果都要存在，效果都有 `at`）。如果 `ContentDb.Validate()` 还是 private，改成 public（验收测试要直接调用；FromJson 里照常调用）。
4. `Tools/PackCheck` 的“没被用到的技能”提醒同样覆盖包里自带的技能；`--write-docs` 生成的名单文档标出哪些技能/人设是本包独有的。
5. `docs/design.md` 6.3 内容包格式补上这四个字段。
