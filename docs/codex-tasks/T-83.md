# T-83 回看用的回合游标（前进、后退、跳转）

依赖：T-34（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
回看界面（T-70）需要在录像里自由前进、后退、跳到任意回合，并且每一步都能拿到画面数据。

## 要做的
1. 新文件 `Core/View/ReplayCursor.cs`：`ReplayCursor(ContentDb db, BattleRecord record, int snapshotEvery = 5)`。
   - `int Turn`、`int MaxTurn`、`Battle Current`（只读用途，调用方不得修改）。
   - `bool Next()`、`bool Prev()`、`void Seek(int turn)`、`void ToEnd()`。
   - `IReadOnlyList<BattleEvent> EventsOfCurrentStep`：最近一次前进那一步产生的事件（给动画用）；后退和跳转后为空列表。
   - `BattleViewModel View(int viewerSide)`。
2. 实现：每 `snapshotEvery` 回合用 `Battle.Clone()` 存一个快照，后退和跳转从最近的快照重放，不从头重放；补位、首发、禁用步骤也算在回合内正确处理。
3. 结果必须与 `Replay.Run` 完全一致：任何回合的 `StateHash()` 与从头重放到该回合相同。

## 验收
自带测试 `Engine.Tests/T83_ReplayCursorTests.cs`：随机 10 局，在每局里随机前进、后退、跳转 50 次，每次 `StateHash` 与从头重放到同一回合一致；越界跳转被夹到 0 和 MaxTurn；`EventsOfCurrentStep` 与正常对战那一回合的事件一致。
