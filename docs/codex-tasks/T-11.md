# T-11 组队页的赛季选择和对战回看（需要本机有 Unity）

依赖：T-01、T-02、T-09（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
玩家能选赛季，不合法的队伍不能开播；每局自动存档，能回看。

## 要做的
1. 组队页加赛季下拉（来自内容包 `seasons`，外加“不限”）。队伍不合法时开播按钮不可点，下面列出 `TeamCheck.Validate` 返回的全部中文错误。
2. 每局结束把 `Battle.Record.ToJson()` 存到 `Application.persistentDataPath/replays/<时间>_<packId>.json`，最多保留 50 个，超出删最旧的。
3. 组队页加“回看”列表（时间、双方首发、胜负）。点开后用 `Replay.Run` 重建对战，用对战页逐行播放，不能操作，只能暂停/快进/退出。
4. 回看文件的 PackId 和当前内容包不一致时，提示“这局用的是其他内容包”，并自动切换内容包后播放；找不到该包就提示无法回看。

## 验收
截图：赛季报错、回看列表、回看播放中。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过。
2. 本机 Unity 打开工程 Console 无红色报错、无黄色警告；按 Play 能完整打完一局。PR 里写 Unity 版本，附截图（存到 PR 评论或描述里，不要提交进仓库）。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
**本机没有安装 Unity 就不要领这个任务**（跳过它领下一个）。不要自己安装 Unity。
