# T-15 新机制：偷强化、反弹、免疫弱化、禁止换人

依赖：T-03（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
再补四个赛尔号式机制（只借鉴机制，名字和数值是我们自己的）。

## 要做的
1. 新效果码（在 `Battle` 新文件 `Battle.Effects2.cs` 里实现，`RunEffect` 只加分派）：
   - `STEAL_BOOST`（target）：把目标所有 > 0 的能力等级加到自己身上（每项上限 +6），目标这些等级归零。日志写清转移了哪些。
   - `FIELD` 新增三个直播间效果（写进 `StreamDuelRules.json` 的 `fields`）：
     - `mirror`「镜面回击」，kind `turn`，3 回合：受到伤害后，攻击方受到本次伤害 × 0.3（至少 1，不触发对方人设）。
     - `firewall`「防火墙」，kind `turn`，3 回合：期间免疫弱化类状态（施加时写日志“被防火墙挡下”）。
     - `lockin`「锁麦」，kind `turn`，2 回合，挂在**对手**身上：期间不能主动换人（`LegalFor` 里去掉换人；被击倒补位不受影响）。
2. 新技能 4 个（写进 `skills`，id 和名字自己起，原创中文，不得用赛尔号名字）：一个用 `STEAL_BOOST` 的伤害技能、三个分别挂上述效果的变化技能。暂不分配给任何主播。
3. `Describe.cs` 给新效果码和新效果加说明；`docs/design.md` 6.1 效果码表、5.2 效果表加行。
4. 电脑对手（`Ai.cs`）给这些新效果合理估值（对手有强化时偷强化加分、己方被锁时不换人等）。

## 验收测试（你自己写）
