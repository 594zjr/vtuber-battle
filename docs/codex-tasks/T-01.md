# T-01 赛季规则：禁用池与限制池

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
内容包可以定义赛季；组队时用一个函数检查队伍是否合法。

## 要做的
1. 内容包 JSON 新增可选字段 `seasons`，格式：
   ```json
   "seasons": { "s1": { "name": "第一赛季", "banned": ["kei"], "limited": [ { "max": 1, "ids": ["bell", "bee"] } ] } }
   ```
   在 `UnityProject/Assets/StreamDuel/Resources/Packs/original.json` 里加上正好这个 `s1`。
2. `Core/Content.cs`：`ContentDb` 增加 `Seasons`（id → 赛季定义：Name、Banned 列表、Limited 列表每项含 Max 和 Ids），读取内容包时解析；`Validate()` 检查赛季里引用的主播 id 都存在，不存在就抛 `KeyError` 并指出是哪个赛季哪个 id。
3. 新文件 `Core/TeamCheck.cs`：
   `public static List<string> Validate(ContentDb db, string seasonId, IList<string> team)`
   返回中文错误列表，空列表表示合法。依次检查：正好 6 位；没有重复；每个 id 都存在；不在禁用池；每个限制池里的人数不超过 max。错误信息要写主播的显示名（不是 id）和原因，例如“铁壁老K 在第一赛季禁用池中”。`seasonId` 为 null 时只做前三项检查；seasonId 不存在时返回一条错误。
