# T-65 数值平衡：胜率检查与调整

依赖：T-38（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
用电脑对战量化每位主播的胜率，把明显过强或过弱的主播调回正常范围。

## 要做的
1. 新文件 `Core/BalanceCheck.cs`：`public static Dictionary<string, double> WinRates(ContentDb db, int gamesPerStreamer, uint seed, AiLevel level)`。每局随机组两队（随机只能来自以 seed 初始化的 `Rng`），双方都用同一难度电脑打完；返回每位主播「在场队伍的胜率」（平局算半胜）。同样参数结果完全一样。
2. 跑 `original`、`original_wave2`、`fan_asoul_vr`、`fan_holo_niji` 四个包（Normal 难度，每位至少 200 局），把结果写进新文件 `docs/balance.md`（表格：主播、胜率、调整前后）。
3. 胜率不在 35%～65% 的主播：**只调数值**（六项能力、技能威力/PP/命中、人设参数），不改名字、文案、技能结构和效果码。每次调整写进 `docs/balance.md`。
4. 调完重新跑一遍，四个包所有主播都在 35%～65% 之间。

## 不要做
- 不改任何主播的名字、人设文字、简介；不新增或删除主播。

## 验收测试
把 `Engine.Tests/Pending/T65_BalanceTests.cs` 移到 `Engine.Tests/`，让它通过。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
