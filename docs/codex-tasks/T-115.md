# T-115 本地赛事增加单败和双败淘汰赛

依赖：T-89（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
本地赛事（T-89）目前有循环赛和瑞士轮。再加单败淘汰和双败淘汰两种赛制，朋友聚会时常用。

## 要做的
1. `Tournament` 增加 `SingleElimination` 和 `DoubleElimination` 赛制（文件可拆成 `Tournament.Elimination.cs`）。人数不是 2 的幂时按种子顺序给前几名轮空；种子顺序由创建时给定或用赛事种子确定性打乱。
2. 双败：胜者组、败者组、总决赛；总决赛败者组选手需要连胜两场（写进 design.md，可在创建时关掉「重置总决赛」）。
3. 每场可设为一局或三局两胜（复用现有多局结构，如 T-54 已合并则直接用它的赛制配置，否则先只支持一局）。
4. 存档、续赛、战报（T-110 的 `TournamentReport`）都支持新赛制；`Tools/Cli` 的赛事命令加 `--format single|double`。

## 验收
自带测试 `Engine.Tests/T115_EliminationTests.cs`：4、5、8 人单败的轮次和轮空正确；8 人双败每人恰好输两场才出局（冠军除外）；总决赛重置开和关两种结果正确；同一种子两次生成的对阵完全一致；中途存档再读取后续赛结果与不中断一致。
