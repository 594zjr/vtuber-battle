# T-124 赛事按排位分自动排种子

依赖：T-115、T-57（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
本地赛事（尤其是淘汰赛）现在按报名顺序或随机排种子。增加「按排位分排种子」，让强者不会太早相遇。

## 要做的
1. 赛事创建时种子方式增加 `ByRating`：读取每位选手档案里当前赛季（T-119）的排位分，分高的种子靠前；同分按已完成场数多者靠前，再同按报名顺序。
2. 电脑选手没有档案时按难度给固定参考分（普通 1400、困难 1600、专家 1800，写进 design.md）。
3. 赛事存档记录排种子时使用的分数快照，之后分数变化不影响已创建的赛事。
4. `Tools/Cli` 赛事命令加 `--seed-by rating`。

## 验收
自带测试 `Engine.Tests/T124_RatingSeedTests.cs`：种子顺序符合分数、场数、报名顺序三级排序；电脑选手使用参考分；创建后修改档案分数不改变赛事对阵；存档读取后种子快照不变；8 人单败中第 1、2 种子分在不同半区。
