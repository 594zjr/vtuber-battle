# T-40 结构化战斗事件（给画面动画用）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
画面要做飘字、血条缓动、下播动画，需要机器能读的事件，而不是去解析日志文字。这是 Unity 画面任务的前置，本身不需要 Unity。

## 要做的
1. 新文件 `Core/BattleEvent.cs`：
   - `public enum BattleEventKind { Act, Damage, Heal, Faint, Enter, Switch, StatusAdd, StatusRemove, FieldAdd, FieldRemove, StageChange, PpChange, Crit, Miss, Info, End }`
   - `public sealed class BattleEvent { public int LogIndex, Turn, Side, Slot, Amount; public string Node, Id; public BattleEventKind Kind; }`（`Id` 为技能/状态/效果/能力名，`Amount` 为数值，含义写在注释里）。
2. `Battle.Events`（只读列表）：在每处写日志的地方同时追加对应事件，`LogIndex` 指向那一行日志；一行日志可以对应 0～多个事件，顺序与发生顺序一致。
3. 要求：每位主播所有 `Damage`（减）和 `Heal`（加）的 `Amount` 之和等于最终人气减最大人气；每次下播恰好一个 `Faint`；每条 `Kind == "act"` 的日志恰好一个 `Act`；开场和换人有 `Enter`/`Switch`。
4. `Battle.Clone()` 拷贝事件列表；`StateHash` 不需要包含事件。
5. `docs/design.md` 第 8 节补“画面通过 `Battle.Events` 播放动画”。
