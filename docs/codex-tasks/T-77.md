# T-77 伤害计算器与阵容对位表

依赖：T-05、T-39（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
组队时可以不开局直接算「我的 A 打对面的 B 能打多少」，并看两支队伍的对位强弱。

## 要做的
1. 新文件 `Core/DamageCalc.cs`：`public static Battle.DamagePreview Range(ContentDb db, string attackerId, int skillIndex, string defenderId, IDictionary<string,int> attackerStages = null, IDictionary<string,int> defenderStages = null)`：内部建一个临时对战（两位分别首发）调用 `PreviewDamage`，结果与对战中预览完全一致；不影响任何外部状态。
2. `public static int[,] Matchup(ContentDb db, IList<string> teamA, IList<string> teamB)`：`[i,j]` = A 队第 i 位对 B 队第 j 位所有可用技能里最高的平均伤害占对方最大人气的百分比（0～100+，四舍五入）。
3. `Tools/Cli` 加 `--calc <攻击方id> <技能序号> <防守方id>` 和 `--matchup <6 个 id> vs <6 个 id>`（表格输出）。
4. 不消耗任何外部随机数（临时对战自己的 `Rng` 不算）。

## 验收
自带测试 `Engine.Tests/T77_DamageCalcTests.cs`：与同样首发的真实对战里的 `PreviewDamage` 结果一致；状态技能为 0；能力等级 +2 时伤害上升；对位表 6×6 且全部非负；同样输入结果一致。
