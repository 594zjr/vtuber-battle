# T-91 电脑出招说明（为什么这样选）

依赖：T-33（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
可以看到电脑每一步「考虑了哪些选项、各自打多少分」，方便调电脑，也可以在对战里给玩家当参考。

## 要做的
1. 新方法 `Ai.Explain(Battle b, int s, AiLevel level)` 返回 `AiExplanation { BattleAction Chosen; List<AiOption> Options; }`；`AiOption { BattleAction Action; double Score; List<string> Reasons; }`（理由用中文，例如「克制对方 ×2」「对方残血可击倒」「PP 不足」）。按分数从高到低。
2. `Chosen` 必须与同参数下 `Ai.Choose` 的结果完全一致；调用 `Explain` 不改变对战状态、不消耗随机数（需要随机的难度，用对战的克隆或单独记录说明随机部分）。
3. `Tools/Cli` 加 `--explain`：每回合打印电脑的前 3 个选项。
4. 不在 Core 之外重写打分逻辑：把现有打分函数整理成可以同时给 `Choose` 和 `Explain` 用的形式。

## 验收
自带测试 `Engine.Tests/T91_AiExplainTests.cs`：四个难度在随机 20 个局面里 `Explain().Chosen` 都等于 `Choose()`；调用前后 `StateHash` 不变；选项按分数排序；每个选项至少一条理由。
