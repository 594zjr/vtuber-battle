# T-96 联网抗丢包：模拟延迟丢包与重发

依赖：T-29（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
真实网络会延迟、乱序、丢包。用模拟传输把这些情况测出来，并让联网对战扛得住。

## 要做的
1. 新文件 `Core/Net/LossyTransport.cs`（测试和工具用）：包装任意 `INetTransport`，按参数模拟延迟（按 Poll 次数计）、乱序、丢包率、重复包；随机数来自构造时给的种子。
2. `NetSession` 增加消息序号和确认：每条消息带递增序号，对方回确认；超过 N 次 Poll 没确认就重发；重复的消息按序号丢弃；乱序的按序号排队处理。TCP 下这些开销很小，但要保证在不可靠传输上也正确。
3. `ProtocolVersion` 加 1；更新 `docs/netplay-protocol.md`（T-79 已合并）和固定消息样例。
4. 与断线重连（T-75，如果已合并）配合：重连后序号从对方确认的位置继续。

## 验收
自带测试 `Engine.Tests/T96_LossyNetTests.cs`：在丢包 20%、乱序、重复、延迟的模拟网络上打完 20 局，双方哈希一致、没有进入 Desync；丢包 100% 超过时限进入 Error；同种子结果一致。
