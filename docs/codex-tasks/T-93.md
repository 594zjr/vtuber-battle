# T-93 旧版本录像兼容

依赖：T-30、T-80（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
以后改规则或格式，玩家以前存的录像仍然能打开：能重放的照常重放，不能重放的给出清楚提示。

## 要做的
1. 新目录 `Engine.Tests/Golden/replays/`：用当前代码生成至少 8 份录像（覆盖：普通、首发选择、禁用、规则修饰器、多局制、联网记录、同人包、第二期包），连同每份的最终 `StateHash` 一起保存。
2. `BattleRecord.FromJson` 支持所有历史版本（v1、v2 以及现在的版本）：缺字段按当时的默认值补齐；未来版本号给出「录像来自更新的版本」的中文提示而不是崩溃。
3. 新方法 `Replay.Check(ContentDb db, BattleRecord r)` 返回 `ReplayCompat { bool CanReplay; string Reason; }`：内容包缺失、内容哈希不同（规则改过）、版本过新等情况给出中文原因；内容哈希不同时仍允许「尽力重放」但标明结果可能不同。
4. `docs/design.md` 写明录像版本规则：什么改动必须升版本号、升了以后要在 `Golden/replays` 加新样例。

## 验收
自带测试 `Engine.Tests/T93_ReplayCompatTests.cs`：所有黄金录像重放后哈希一致；手工构造的 v1 记录能读；未来版本号给出中文提示；内容哈希不同给出提示且 `CanReplay` 为 true 但带警告。
