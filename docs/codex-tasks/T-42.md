# T-42 文本表与本地化基础

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
把写死在代码里的中文提出来，放进文本表，为以后的英文/日文版本做准备。这次只做基础设施和一部分迁移。

## 要做的
1. 新文件 `Core/Loc.cs`：
   - `public sealed class Loc { public string Language; public static Loc FromJson(string json, Loc fallback = null); public string T(string key, params object[] args); public bool Has(string key); public static Loc Current; }`
   - JSON 格式：`{"language":"zh-CN","texts":{"key":"文本 {0}"}}`，`{0}` 等用 `string.Format`（`CultureInfo.InvariantCulture`）。缺键时先查 fallback，再找不到返回 `[key]`。
   - `Loc.Current` 默认在第一次使用时从内置的中文表初始化：中文表放 `UnityProject/Assets/StreamDuel/Resources/Locale/zh-CN.json`；Core 不能读 Unity 资源，所以由调用方注入（测试和工具用文件读取，Unity 用 `Resources.Load`），没注入时用编进代码的同一份 JSON 字符串（自动生成或手写常量均可，必须与文件一致，加一个测试检查一致）。
2. 迁移至少 30 条：`TeamCheck` 的全部错误、`Describe.cs` 的全部说明文字、`PackLoader` 的错误。写法统一为 `Loc.T("xxx.yyy", ...)`（测试会扫描这种写法）。键名用小写英文加点。迁移后输出的中文必须与原来**完全一样**（现有测试会检查）。
3. **不要**迁移 `Battle` 的日志文字（以后单独做，避免和其他任务冲突）。
4. `docs/design.md` 加一节“文本与语言”。
