# T-105 战斗记录筛选与搜索

依赖：T-40（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战界面和回看里的战斗记录很长，需要能按回合、按一方、按类型筛选，并能搜索文字。

## 要做的
1. 新文件 `Core/View/LogFilter.cs`：`LogQuery { int? Turn; int? Side; HashSet<string> Kinds; string Text; bool OnlyImportant; }`；`public static List<int> Apply(Battle b, LogQuery q)` 返回匹配的 `Battle.Log` 下标。
2. 「重要」的定义：击倒、暴击、克制、控制生效/解除、直播间效果生效、人设触发、换人、对战结束；写进 design.md。
3. `public static List<LogGroup> GroupByTurn(Battle b)`：按回合分组，每组带摘要（例如「第 5 回合：铃铛 击倒 汐汐」）。
4. 文字搜索不区分全角半角和大小写；性能：1000 行日志筛选在 5 毫秒内。

## 验收
自带测试 `Engine.Tests/T105_LogFilterTests.cs`：按回合、按一方、按类型、按文字筛选结果正确；组合条件正确；只看重要时不含普通伤害行；分组摘要非空；空条件返回全部。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
