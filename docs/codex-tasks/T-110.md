# T-110 本地赛事的完整战报汇总与导出

依赖：T-89、T-80（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
本地循环赛或瑞士轮打完后，玩家能一键得到整场赛事的战报：积分榜、每轮对阵与比分、每局录像链接、全场数据之最，方便发给朋友。

## 要做的
1. 新文件 `Core/TournamentReport.cs`：`TournamentReport.Build(Tournament t, ReplayLibrary lib)`（类名以仓库现有实现为准），给出积分榜（含 T-89 已有的同分排序规则）、每轮对阵与结果、每局在录像库里的 id（没有归档的局标明「未保存」）、全场最高单次伤害、最多击倒的主播、出场最多的主播。
2. 输出两种格式：纯文本（中文，适合粘贴到聊天）和 JSON（字段名写进 design.md）。
3. 只读：不修改赛事状态和录像库；不包含任何账号、设备、网络信息；玩家名经 T-97 的文字过滤。
4. `Tools/Cli` 加 `--tournament-report <赛事文件> [--json]`。

## 验收
自带测试 `Engine.Tests/T110_TournamentReportTests.cs`：用固定种子跑一场 4 人循环赛和一场 6 人 3 轮瑞士轮，积分榜与 `Tournament` 自身结果一致；数据之最可从录像独立复算一致；缺录像的局标明「未保存」；同一输入两次输出逐字节相同；生成报告前后赛事文件和录像库内容不变。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
