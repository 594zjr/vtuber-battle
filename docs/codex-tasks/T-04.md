# T-04 平衡模拟命令行工具

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
一个命令行工具，让电脑对电脑打很多局，统计每位主播的强弱，给调数值用。

## 要做的
1. 新工程 `Tools/Sim/Sim.csproj`（net8.0，`<ProjectReference Include="../../Engine/StreamDuel.Core.csproj" />`），读取 `UnityProject/Assets/StreamDuel/Resources/StreamDuelRules.json` 和指定的内容包。
2. 用法：`dotnet run --project Tools/Sim -- --pack original --games 5000 --seed 1`。每局从内容包里随机抽 12 位分成两队（用 `--seed` 决定的 `System.Random` 只用来抽阵容；对战本身用 `Battle` 的种子），双方都用 `Ai.Choose` / `Ai.ChooseReplacement`。
3. 输出 CSV 到标准输出，列：`id,name,games,wins,winrate,avg_turns`，按胜率从高到低；再输出第二段 CSV：`skill_id,skill_name,uses`。标准错误输出一行总结（总局数、平局数、耗时）。
4. 同样的参数两次运行输出必须完全一致。
5. README 的“结构”表格下面加一行用法说明。
