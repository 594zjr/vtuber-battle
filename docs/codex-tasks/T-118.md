# T-118 淘汰赛平局自动加赛

依赖：T-115（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
淘汰赛（T-115）一场打成平局时现在只能停下来手工处理。改成按固定规则自动加赛，赛事能一口气打完。

## 要做的
1. 淘汰赛一场（或三局两胜的决胜局）平局时自动加赛，最多 3 次；加赛种子由「赛事种子、场次编号、加赛序号」确定性派生（写进 design.md）。
2. 3 次加赛仍平局：种子顺位高的一方晋级，战报里写明「加赛 3 次仍平，按种子顺位晋级」。
3. 加赛的每一局都进录像库和 T-110 战报；存档和续赛支持加赛中途中断。
4. 创建赛事时可关闭自动加赛（关闭时保持 T-115 的手工处理方式）。

## 验收
自带测试 `Engine.Tests/T118_TiebreakTests.cs`：构造必平局面（可用规则修饰器或固定种子）时自动加赛并产生胜者；同一赛事种子两次结果一致；3 次全平时种子高者晋级且战报文字正确；加赛中途存档续赛结果与不中断一致；关闭自动加赛时行为与 T-115 一致。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
