# T-100 联网掉线后由电脑代打（可选）

依赖：T-55、T-29（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
联网对战中对方超时或掉线时，房主可以选择「电脑代打把这局打完」，而不是直接结束。

## 要做的
1. `NetSession` 选项 `AiTakeoverOnTimeout`（握手时由主机声明，双方都要知道）：一方总时间用完或掉线超过时限后，由**双方本地**用同样的 `Ai.Choose(b, side, AiLevel.Normal)` 为该方出招（确定性，双方算出同样的行动，不需要网络传输）。
2. 代打的回合在日志和录像里标明「电脑代打」；该方重新连上（T-75 已合并时）后可以从下一回合收回控制。
3. 排位（T-57）：被代打的一方结果照常计算，但 `BattleSummary` 标记 `AiTakeover`，以后可以据此调整规则。
4. 默认关闭；`Tools/Cli` 加 `--ai-takeover`。

## 验收
自带测试 `Engine.Tests/T100_AiTakeoverTests.cs`：模拟一方超时后双方本地代打行动一致、整局打完哈希一致；关闭选项时行为与原来一致；代打标记出现在录像和统计里。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
