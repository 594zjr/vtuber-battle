# T-22 双赛道

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
像赛尔号的双属性一样，主播可以有第二赛道。

## 要做的
1. `StreamerDef` 加 `Type2`（可为 null）；内容包里可选字段 `type2`。如果 `ContentDb.Validate()` 还是 private，改成 public（验收测试要直接调用；FromJson 里照常调用）。校验：`type2` 必须存在于赛道表，且不能与 `type` 相同，否则抛 `KeyError`。
2. 克制倍率 = 对第一赛道的倍率 × 对第二赛道的倍率。同赛道加成（×1.5）：技能赛道等于主播任一赛道即生效，只算一次。
3. 所有用到防守方赛道的地方都要改：伤害、`PreviewDamage` 的 `Eff`、电脑对手的对位分、`Describe` 和名单文档（显示为“歌回/杂谈”）、CLI 显示。IMGUI 画面（`Game/`）里显示赛道的地方一起改，只改显示文字。
4. 不给现有任何主播加第二赛道（以后由内容任务决定），所以现有对战结果完全不变。
5. `docs/design.md` 第 4 节写明双赛道规则。
