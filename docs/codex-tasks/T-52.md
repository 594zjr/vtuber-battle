# T-52 性能基准工具

依赖：T-35（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
知道引擎和各难度电脑有多快，防止以后变慢。

## 要做的
1. 新命令行工程 `Tools/Bench/Bench.csproj`（net8.0，Release 运行）：`dotnet run -c Release --project Tools/Bench -- [--quick]`，输出：每秒能跑多少局（普通对普通）、每种难度单次决策的平均/95 分位/最大耗时、`Battle.Clone()` 和 `StateHash()` 的单次耗时、内容包加载耗时。结果打印表格并写 `bench_out/bench.json`。
2. 先预热再计时；用 `Stopwatch`；固定种子。
3. `docs/performance.md`：记录本机一次结果（写明 CPU 型号）和参考上限（例如专家单次决策平均 ≤ 50 毫秒）。
4. 不加单元测试（计时类测试在 CI 上不稳定）。

## 验收
`--quick` 一分钟内跑完；PR 里贴出结果表。
