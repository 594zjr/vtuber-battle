# T-74 战后复盘：关键回合提示

依赖：T-23、T-40（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战结束后告诉玩家「这局是在哪几回合打赢/打输的」，帮助提高对战水平。

## 要做的
1. 新文件 `Core/BattleReview.cs`：`public static List<KeyMoment> KeyMoments(Battle b, int viewerSide, int max = 5)`；`KeyMoment { int Turn; string Kind; string Text; int Swing; }`。
2. Kind 至少包括：`ko`（击倒）、`swing`（单回合双方人气差变化最大的回合）、`control`（成功控制对方导致对方跳过行动）、`switch`（换人后吃到克制减伤或打出克制）、`comeback`（人气落后一半以上后翻盘的起点回合）。
3. 按 `|Swing|` 从大到小取前 `max` 个，再按回合排序；文本走 `Loc`，说清回合、谁、做了什么、结果（例如「第 7 回合：雷音铃铛 击倒 深海汐汐，你方领先 2 人」）。
4. 只读 `Battle.Log`/`Battle.Events`，不消耗随机数，不改对战状态。
5. `Tools/Cli` 结束后打印复盘；`BattleReport.Markdown`（T-37）末尾加「关键回合」一节。

## 验收
自带测试 `Engine.Tests/T74_BattleReviewTests.cs`：固定种子打完一局，至少有一个 `ko`；结果按回合排序；数量不超过 max；同一局调用两次结果一致；对战状态哈希调用前后不变。
