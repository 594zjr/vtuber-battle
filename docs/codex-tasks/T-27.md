# T-27 从外部文件夹加载内容包

依赖：T-19（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
开源后别人自己部署时，不改代码、不进 Unity，往一个文件夹里放 JSON 就能加新内容包。

## 要做的
1. 新文件 `Core/PackLoader.cs`：
   - `public sealed class PackLoadResult { public string FileName, Error; public ContentDb Db; }`
   - `public static List<PackLoadResult> LoadDirectory(string rulesJson, string dir)`：读取 `dir` 下所有 `*.json`（不递归，按文件名排序）；每个文件独立解析和校验，出错时 `Error` 写中文原因、`Db` 为 null，**不抛异常**；包 id 与前面已成功加载的重复时也算错误（信息里写出 id）。目录不存在返回空列表。
   - Core 里只用 `System.IO`，不引用 Unity。
2. `Tools/Cli`、`Tools/Sim`、`Tools/PackCheck` 加 `--pack-dir <文件夹>`，与内置包一起列出（内置包同名时内置优先，并提示）。
3. Unity 画面（`Game/BattleScreen.cs`）启动时额外读取 `Application.persistentDataPath/packs/`，加载失败的包在组队页顶部显示一行错误，不影响其他包。只改显示和加载调用。
4. README 加“自制内容包”一节：放哪里、格式看 design.md 6.3、同人包必须遵守的规则（链接 FANWORK.md）。
