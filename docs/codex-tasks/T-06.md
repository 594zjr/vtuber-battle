# T-06 电脑难度：简单 / 普通

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
电脑对手可选难度，新手可以先打简单。

## 要做的
在 `Core/Ai.cs`：
1. 新增 `public enum AiLevel { Easy, Normal }`。
2. 新增 `public static BattleAction Choose(Battle b, int s, AiLevel level)`。`Normal` 和现有的 `Choose(b, s)` 完全一样（现有两参数版本保留，行为不变）。`Easy`：被控制时跳过；所有技能没 PP 时硬撑；否则一半概率从可用技能里随机选一个，一半概率用普通难度的选择，但**从不主动换人**（普通难度想换人时改用第一个可用技能）。所有随机数用 `b.Random()`。
3. 补位仍然用现有的 `ChooseReplacement`。

## 验收测试
把 `Engine.Tests/Pending/T06_AiLevelTests.cs` 移到 `Engine.Tests/`，让它通过（普通难度对简单难度 300 局至少赢 60%）。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 开一个 PR，标题以任务编号开头，描述里写：做了什么、改了哪些文件、测试输出的最后一行。
