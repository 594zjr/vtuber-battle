# T-122 观众之间的快捷语（不打扰选手）

依赖：T-58、T-62（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
观战（T-58）时观众之间可以发固定短句（复用 T-62 的快捷语表），给观战增加一点互动，但不会发给对战的两位选手，也不影响对战。

## 要做的
1. 观战协议增加观众快捷语消息：观众发给主机，主机转发给其他观众；**不转发给选手**，不进入战斗状态、录像或状态哈希。作为可选扩展，旧观众端忽略它（写进 `docs/netplay-protocol.md`，版本号按决定记录由审查员合并时分配）。
2. 只能发快捷语表里的固定短句（按编号），不允许自由文字；每位观众每回合最多 3 条，超出丢弃。
3. 观众显示名沿用现有文字过滤；主机可以在 CLI 用 `--spectator-chat off` 关闭。
4. `Tools/Cli` 观战端加 `/say <编号>`。

## 验收
自带测试 `Engine.Tests/T122_SpectatorChatTests.cs`（用 `LoopbackPair`）：一位观众发的短句其他观众收到、选手收不到；非法编号被丢弃；超过每回合上限被丢弃；关闭后不转发；有观众聊天和没有时对战 `StateHash` 相同；旧观众端收到这种消息时不报错。
