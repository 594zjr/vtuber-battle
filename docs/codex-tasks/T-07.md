# T-07 GitHub 自动测试（CI）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
每个 PR 和每次推到 main 都在 GitHub 上自动跑引擎测试，审查员一眼就能看到红绿。

## 要做的
1. 新文件 `.github/workflows/test.yml`：触发 `pull_request` 和 `push` 到 `main`；`ubuntu-latest`；`actions/checkout@v4`、`actions/setup-dotnet@v4`（dotnet-version `8.0.x`）；运行 `dotnet test Engine.Tests --logger "console;verbosity=normal"`。
2. 同一个 workflow 再加一个 job：`dotnet build Engine/StreamDuel.Core.csproj -warnaserror`，保证 Core 没有警告。
3. README 顶部加一个 CI 状态徽章。

## 验收
PR 页面上两个检查都是绿的。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
