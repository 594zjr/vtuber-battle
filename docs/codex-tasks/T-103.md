# T-103 效果码与设计文档一致性检查

依赖：T-21（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
保证 `docs/design.md` 的效果码表、人设代码表与代码里实际支持的完全一致，以后加新码不会漏写文档。

## 要做的
1. 在 Core 里提供注册表：`EffectCodes.All`、`PersonaCodes.All`（每项：代码、判定时机、驱散规则、参数名列表、中文说明来源），由现有实现整理而来，不改变任何行为。
2. 自带测试 `Engine.Tests/T103_CodeDocConsistencyTests.cs`：解析 `docs/design.md` 里的两张表，与注册表逐项比对（代码集合相同、参数名相同、判定时机相同）；`Describe.cs` 对每个代码都有说明；内容包里用到的代码都在注册表里。
3. 新工具命令 `Tools/PackCheck --codes`：列出每个代码被哪些内容包的哪些技能/人设使用、没有被任何内容使用的代码。
4. 如果比对发现文档和代码不一致，**以代码现状为准修文档**，并在 PR 里列出每处差异。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
