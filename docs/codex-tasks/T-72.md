# T-72 原创主播第三期内容包（12 位）

依赖：T-36（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
再加 12 位原创主播，让对战阵容更多样。

## 要做的
1. 新内容包 `Resources/Packs/original_wave3.json`，id 一律 `og3_` 开头，12 位原创主播：名字、简介、人设、4 个技能 + 第五技能全部原创；覆盖全部赛道，至少 3 位双赛道（T-22）。可以用包内自定义技能/人设/状态（T-19），也可以复用规则里已有的。
2. 每位主播要有清楚的打法定位（快攻、消耗、控制、强化、反击、辅助各至少一位），写在简介里。
3. 风格要求：可爱、积极的直播题材；不得影射任何真实主播或公司；不出现现实事件、负面、擦边内容；不出现赛尔号的名字和文本。
4. 用 `Tools/Sim` 或 `BalanceCheck`（T-65 合并后）跑一遍，每位主播胜率在 35%～65% 之间；结果写进 PR。
5. `Tools/PackCheck` 通过；README 的内容包列表加一行（不要改同人声明段落）。

## 验收
自带测试 `Engine.Tests/T72_OriginalWave3Tests.cs`：包能加载并通过 `Validate()`；12 位、id 都以 `og3_` 开头且不与其他包重复；每位有 4 个技能和第五技能；随机 20 局电脑对战都能正常结束。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
