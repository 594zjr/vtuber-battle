# T-132 可替换的外部特效与图标图片约定

依赖：T-61、T-123（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
现在特效和状态图标都是代码画的（T-69）。以后想换成手绘图片时，需要一个路径约定，放进内容包目录就能替换，不放就继续用代码画的。

## 要做的
1. `ArtManifest` 增加特效和图标的可选图片路径约定：`Fx/<packId>/<fxId>.png`、`Icons/<packId>/<iconId>.png`（序列帧特效可用 `<fxId>_00.png` 起编号，帧数和帧率写进同目录的小 JSON，格式写进 design.md）。
2. T-123 的检查工具按新约定检查这些图片（缺失允许，格式和尺寸错误报出）。
3. Core 只提供路径和帧信息查询，不加载图片；Unity 侧的加载与回退由画面任务接入（本任务不改 Unity 文件）。
4. 重申：只放自己画的或有授权的图片，不放官方素材。

## 验收
自带测试 `Engine.Tests/T132_FxArtPathTests.cs`：路径生成符合约定；序列帧 JSON 解析与错误处理正确；检查工具对缺失、格式错、帧号不连续给出正确报告；没有任何图片时一切照常（全部回退代码绘制）。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
