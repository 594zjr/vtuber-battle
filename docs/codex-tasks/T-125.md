# T-125 排位赛季总结

依赖：T-119、T-80（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
一个赛季结束（或随时查看）时，给玩家一份本赛季的对战总结。

## 要做的
1. 新文件 `Core/SeasonSummary.cs`：从录像库（T-80）里本赛季的排位对局和档案的赛季记录（T-119）生成：场数、胜/负/平、胜率、最高分和最终分、段位变化、最常用的 3 位主播及其胜率、最常遇到的对手主播、最长连胜。
2. 只统计排位对局；对电脑、同屏、回看接手（T-116 的 `IsBranch`）、离线续局都不计入。
3. 录像库里缺少某些对局时，按档案记录的场数提示「有 N 局录像缺失，部分统计不完整」。
4. `Tools/Cli` 加 `--season-summary [赛季号]`，中文输出。

## 验收
自带测试 `Engine.Tests/T125_SeasonSummaryTests.cs`：构造一个含排位、非排位和接手对局的录像库，统计只算排位对局且数字正确；最长连胜计算正确；缺录像时给出提示；历史赛季可单独查询；不修改录像库和档案。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
