# T-106 本机存档整体备份与恢复

依赖：T-43、T-80、T-56（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
换电脑或重装时，玩家可以把设置、队伍预设、录像库、本机统计一次性导出成一个文件，再导入回来。

## 要做的
1. 新文件 `Core/Backup.cs`：`Backup.Export(ISaveStore store, string replayDir)` 生成一个 zip（`System.IO.Compression`）或单个 JSON 文件（自选，写进 design.md），包含版本号、导出时间（调用方传入）、设置、队伍预设、录像（可选是否包含）、录像库索引。
2. `Backup.Import(...)`：先校验版本和内容（坏文件、未来版本给中文错误，不改动现有数据）；导入方式「合并」（队伍预设同名时加后缀，录像按 id 去重）或「覆盖」（覆盖前自动把现有数据先导出一份备份）。
3. 不包含任何账号、设备、网络信息；路径只在给定目录内。
4. `Tools/Cli` 加 `--backup <文件>`、`--restore <文件> [--overwrite]`。

## 验收
自带测试 `Engine.Tests/T106_BackupTests.cs`（临时目录）：导出再导入到空目录后数据一致；合并模式同名预设加后缀、录像去重；覆盖模式先自动备份；坏文件和未来版本不改动现有数据并给出中文错误。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
