# T-62 对战快捷语（联网对战用的固定短句）

依赖：T-29（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
联网对战时可以发固定的快捷短句（不支持自由输入，避免骚扰和不当内容）。

## 要做的
1. 新文件 `Core/Net/QuickChat.cs`：`public static readonly string[] Lines`，8 句原创短句（例如：你好、打得好、好险、再来一局、我在想、抱歉手滑、谢谢、晚安）。文本走 `Loc`，键名 `quickchat.0`～`quickchat.7`。
2. `NetSession` 增加 `bool SendQuickChat(int index, double now)`（now 为调用方传入的秒数） 和事件/队列 `IReadOnlyList<QuickChatMessage> ReceivedChats`（`Side`、`Index`、`Turn`）。新增消息类型 `chat`，只带编号；编号越界或格式不对直接丢弃，**不影响对战、不算掉线**。
3. 限频：发送方 10 秒内最多 3 条，超出返回 false 且不发送；编号越界也返回 false。接收方另外兜底：同一回合内收到对方超过 6 条时丢弃多出的（防止改过的客户端刷屏）。不读系统时间。
4. `bool MuteOpponent`：为 true 时收到的快捷语不进入 `ReceivedChats`。
5. 快捷语不进入对战记录，不影响 `StateHash`。`ProtocolVersion` 不变（旧版本收到未知类型时的处理如果会报错，就把版本加 1 并在 PR 里说明）。

## 不要做
- 不做自由文字聊天、表情图片、语音。
