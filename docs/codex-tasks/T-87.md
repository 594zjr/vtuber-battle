# T-87 联网对战的公平随机种子

依赖：T-32（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
现在联网对战的随机种子由主机决定，主机理论上可以挑对自己有利的种子。改成双方共同决定。

## 要做的
1. 握手时双方各自生成 32 字节随机数（`System.Security.Cryptography.RandomNumberGenerator`，这是唯一允许不经过 `Battle.Rng` 的随机来源，只用于生成种子），先交换 SHA-256 承诺，再交换原值，种子 = 两份原值拼接后 SHA-256 的前 4 字节（小端）。
2. 原值和承诺不符、超时、重复发送都进入 `Error` 并给出中文原因。
3. 握手完成后双方 `Battle.Seed` 必须相同；`BattleRecord` 里记录最终种子（不记录双方原值）。
4. `ProtocolVersion` 加 1；更新 `docs/netplay-protocol.md`（如果 T-79 已合并）和 `docs/design.md`；旧版本连接时给出「版本不一致」的中文提示。
5. 测试里允许注入固定的随机数，保证可复现。

## 验收
自带测试 `Engine.Tests/T87_FairSeedTests.cs`：双方注入不同随机数时种子相同且等于按规则计算的值；一方篡改原值被拒绝；任一方单独改自己的原值都会改变种子；整局联网对战打完双方哈希一致。
