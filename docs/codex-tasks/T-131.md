# T-131 自定义赛制的保存与分享码

依赖：T-54、T-56（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
玩家想把自己设的赛制（局数、禁用、首发、修饰器、计时）存起来重复用，或者发给朋友。

## 要做的
1. `Profile` 或设置存档增加「我的赛制」列表（上限 20 个），可新增、改名、删除；名称经 T-97 文字过滤。
2. 赛制分享码：前缀 `SDRULE1-`，复用 T-56 队伍码的压缩和校验方式；导入时先 `Validate`，不合法给中文错误，不写入存档。
3. 内置预设（休闲、排位、乱斗）不可删除或修改，只能复制后改。
4. `Tools/Cli` 加 `--ruleset-save <名称> <JSON 或码>`、`--ruleset-list`、`--ruleset-code <名称>`、`--ruleset-import <码>`；`--ruleset` 也接受「我的赛制」名称。

## 验收
自带测试 `Engine.Tests/T131_RulesetShareTests.cs`：导出码再导入后赛制完全一致；篡改一个字符校验失败；不合法赛制（局数 2、未知修饰器）导入被拒且存档不变；超过 20 个时拒绝；内置预设不可删除；旧存档没有该字段时为空列表。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
