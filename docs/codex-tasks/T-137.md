# T-137 观战接入多局赛制

依赖：T-58、T-54（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
观战（T-58）现在只能看单局。一场三局两胜的比赛，观众应该能连续看完每一局，并看到当前比分。

## 要做的
1. 观战流开头发送赛制信息（名称、局数）；每局开始发送局号和比分，每局结束发送该局结果；整场结束发送最终比分。作为观战协议的可选扩展，旧观众端只看到单局流（写进 `docs/netplay-protocol.md`，版本号由审查员合并时分配）。
2. 观战延迟规则（T-58）对每局都生效，比分在该局结果对观众释放后才更新，不提前泄露。
3. 晚加入的观众从当前局开头追赶，并能拿到已结束各局的比分。
4. `Tools/Cli` 观战端显示「第 N 局 比分 a:b」。

## 验收
自带测试 `Engine.Tests/T137_SpectateMatchTests.cs`（用 `LoopbackPair`）：观众看完三局两胜，比分与选手端一致；延迟期间比分不提前更新；晚加入观众拿到已完成局比分；旧观众端只收到单局流且不报错；观战不影响选手端任何哈希。
