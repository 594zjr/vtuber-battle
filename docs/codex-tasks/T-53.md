# T-53 主播专属的电脑出招风格

依赖：T-33（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
电脑操控不同主播时有不同风格（猛攻、稳守、花招），更有“人设感”。

## 要做的
1. 新文件 `Core/AiStyles.cs`：`public static AiWeights Get(string name)`，内置 `aggressive`（伤害和击倒加分高、少换人）、`defensive`（回复/护盾/换人加分高）、`tricky`（状态、驱散、削 PP 加分高）；未知返回 null。
2. `StreamerDef.AiStyle`（可为 null）；内容包主播可选字段 `aiStyle`；校验时未知风格抛 `KeyError`。
3. 普通、困难、专家难度在为某位主播选技能时，若它有 `AiStyle`，用对应权重（困难/专家可以只在它们内部用到普通估值的地方使用）。没有风格时行为**完全不变**。
4. 这次**不给**任何现有主播加风格（以后由内容任务决定），所以现有对战结果不变。
5. `docs/modding.md`（若存在）或 `docs/design.md` 第 9 节写明 `aiStyle`。
