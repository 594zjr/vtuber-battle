# T-114 每次伤害的计算拆解（给战斗记录和画面用）

依赖：T-77、T-41（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
玩家想知道「这一下为什么打了这么多」。每次造成伤害时，记录可读的计算拆解：技能威力、攻防数值、赛道克制倍率、能力等级、暴击、随机系数、人设或直播间效果的加成。

## 要做的
1. 引擎在结算伤害时生成 `DamageBreakdown`（新文件 `Core/DamageBreakdown.cs`，挂在对应的 `BattleEvent` 上或按事件序号查询；不改变任何结算结果和随机数消耗顺序）。
2. 拆解的每一项有中文名和数值，乘起来（按引擎实际取整顺序）等于实际伤害；固定伤害、百分比伤害、延迟伤害等特殊类型单独说明。
3. `BattleViewModel` 或 T-105 的回合摘要可按事件取出拆解文字；`Tools/Cli` 战斗记录里加 `--explain-damage` 开关，在每次伤害后打印一行拆解。
4. 不改动现有录像格式（拆解由重放时重新生成，不写进录像）。

## 验收
自带测试 `Engine.Tests/T114_DamageBreakdownTests.cs`：用固定种子跑四个内容包各 20 局，每次伤害的拆解按顺序复算都等于实际伤害；暴击、克制、能力等级、人设加成各至少覆盖一个用例；开启拆解前后整局 `StateHash` 相同；固定伤害类技能拆解标明「固定伤害」。
