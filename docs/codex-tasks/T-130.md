# T-130 平衡检查结果的版本对比与告警

依赖：T-65（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
T-65 能跑出各内容包的胜率检查结果。改数值或改电脑后，需要知道哪些主播的胜率变化太大。

## 要做的
1. `Tools/Sim`（或 T-65 的工具）增加 `--save-balance <文件>` 把结果存成 JSON（主播 id、出场数、胜率、置信区间、内容指纹、电脑版本、局数、种子）。
2. 新增 `--compare-balance <旧文件> <新文件>`：逐主播对比胜率变化，变化超过阈值且置信区间不重叠的标为「明显变化」，超过平衡上下限的标为「超出平衡范围」（沿用 T-65 的上下限）；中文表格输出，存在「超出平衡范围」时退出码非 0。
3. 两份结果的局数、种子或电脑版本不同时，在报告开头说明「条件不同，对比仅供参考」。
4. 只读，不修改内容包。

## 验收
自带测试 `Engine.Tests/T130_BalanceCompareTests.cs`：构造两份结果文件，明显变化和超出范围被正确标出；置信区间重叠时不标；条件不同时报告开头有说明；同一份文件自比无变化；坏文件给中文错误。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
