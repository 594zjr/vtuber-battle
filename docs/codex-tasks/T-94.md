# T-94 看阵容选人：6 选 3 / 6 选 4 快速对战

依赖：T-25（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
增加更快的对战形式：双方先公开 6 人阵容，再各自秘密选出 3 或 4 人出战。

## 要做的
1. `BattleOptions.PickCount`（0 = 关闭，默认；3 或 4）。开启时新增 `Phase.Pick`：双方看到对方 6 人，各自 `ChoosePick(side, IList<int> indices)` 选出 PickCount 人（顺序即出场顺序，第一位为首发），双方都提交后进入正常流程；与禁用（BanOne）同时开启时，先禁用再选人。
2. 队伍人数不足 6 的局（PickCount 生效后为 3 或 4 人）里所有规则正常：全灭判定、补位、人设里按队伍人数计算的效果（如果有）按实际出战人数。
3. 电脑：`Ai.ChoosePick(b, s, level)`（Easy 随机，其余按对位表挑对位最好的组合）。
4. 录像、`StateHash`、联网（`NetSession` 的承诺-揭示同样用于选人）都支持；`ProtocolVersion` 视需要加 1。
5. `docs/design.md` 写明规则；`Tools/Cli` 加 `--pick 3`。

## 验收
自带测试 `Engine.Tests/T94_PickPhaseTests.cs`：选 3 和选 4 都能打完整局；选人前看不到对方的选择；非法选择（重复、越界、数量不对、选了被禁用的）被拒绝；录像可重放；联网双方哈希一致。
