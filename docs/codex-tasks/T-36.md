# T-36 原创主播第二期内容包（12 位）

依赖：T-19、T-21、T-22（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
新增一个**完全原创**的内容包 `original_wave2`：12 位虚构主播，不涉及任何真人，所以不受同人规则限制，以后商用也不怕。

## 要做的
1. 新文件 `UnityProject/Assets/StreamDuel/Resources/Packs/original_wave2.json`，`id` 为 `original_wave2`，`name` 为“原创主播·第二期”，不写“同人”字样，`org` 写“原创”或留空。
2. 12 位主播，8 个赛道每个至少 1 位，至少 3 位有第二赛道（T-22）。每位都有包内自带的 `og2_` 人设和 `og2_` 第五技能（T-19），人设可以用任何已有代码（含 T-21 新增的）；四个普通技能可以混用规则文件里的技能，但每位的组合要不同。
3. 文案方向：虚构的直播圈角色，题材可以是深夜电台主持、速通玩家、手工博主、天文主播、料理主播、乐队主播、恐怖实况、硬件测评、方言杂谈、像素画师等；每位一句话人设（`blurb` ≤ 40 字），名字是自造的中文昵称。
4. **禁区**：名字、形象、口头禅、设定都不得与任何现实主播、动漫游戏角色或公司 IP 相同或明显相似；不得出现赛尔号（淘米）的任何名字或文本；不写现实事件、擦边、贬损、政治宗教内容；与已有三个包的主播名字和 id 都不能重复。
5. 平衡：`dotnet run --project Tools/Sim -- --pack original_wave2 --games 5000 --seed 1`，每位胜率 40%～60%，写进 `docs/balance.md`。
6. `dotnet run --project Tools/PackCheck -- --pack original_wave2 --write-docs` 无错误，提交名单文档。README 内容包列表加一行。
