# T-16 开场看阵容选首发

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
像赛尔号巅峰那样：开局双方先看到对方 6 位，再各自选首发。

## 要做的
1. 引擎（新文件 `Core/Battle.Lead.cs`）：构造参数加可选 `bool leadPick = false`（保持旧构造函数行为不变）。为 true 时对战从 `Phase.Lead` 开始，双方调用 `ChooseLead(int side, int index)`；两边都选完后把所选主播换到 1 号位（其余顺序不变），写日志（节点“开场”），进入正常流程。
2. `Ai.ChooseLead(Battle b, int s)`：按对位分选出对对手 6 位平均最有利的。只用 `b.Random()` 打破平局。
3. 回放（若 T-02 已合并）：记录里加首发选择事件，`Replay.Run` 能重放；若 T-02 还没合并，在 PR 描述里写明，留给审查员合并时补。
4. 画面：IMGUI 版 `BattleScreen` 加一个简单的首发选择页（对手 6 位卡片 + 我方 6 位可点）。若 T-09 已把画面换成 UI Toolkit，就在新画面里做。
5. `docs/design.md` 第 2 节补一段“首发选择”。

## 验收测试（你自己写）
`Engine.Tests/T16_LeadPickTests.cs`：选首发后 `Active` 正确、其余顺序不变；`leadPick=false` 时行为与旧版一致（同种子日志完全相同）；AI 选首发确定可复现。
