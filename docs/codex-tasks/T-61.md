# T-61 立绘与特效资源清单：按内容包路径加载、可替换

依赖：T-19、T-27（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
立绘、技能特效、状态图标都由内容包声明，画面按路径加载；包里没写就用代码生成的默认值。以后用户画好图或换成 Live2D，只需要往对应路径放资源。

## 要做的
1. 内容包新增可选字段 `art`（写进 `docs/design.md` 的内容包格式一节，并更新 `docs/modding.md`，如果它已存在）：
   ```json
   "art": {
     "portraitDir": "Portraits/original",
     "streamers": { "bell": { "accent": "#ffcc33", "portrait": "bell_v2" } },
     "skillFx": { "full_volume": "wave" },
     "statusIcons": { "stall": "clock" }
   }
   ```
2. 新文件 `Core/ArtManifest.cs`，`ContentDb.Art` 属性（包里没写 `art` 时也不为 null）：
   - `string PortraitPath(string streamerId)`：返回 Unity `Resources.Load` 用的路径（不带扩展名）。默认目录 `Portraits/<packId>`，默认文件名为主播 id；`streamers.<id>.portrait` 可改文件名。
   - `string Accent(string streamerId)`：`#RRGGBB`；没写时取该主播主赛道的 `TypeDef.Color`。
   - `string SkillFx(string skillId)`：没写时按技能分类给默认：互动 `slash`、才艺 `beam`、状态 `sparkle`；带回复效果的状态技能 `heal`，带保护类直播间效果的 `shield`。
   - `string StatusIcon(string id)`：可传状态 id 或直播间效果 id；没写时控制类 `lock`、弱化类 `down`、保护 `shield`、印记 `mark`、回合类 `clock`。
   - `public static readonly string[] FxIds = { "slash", "burst", "wave", "sparkle", "beam", "ring", "shield", "heal" }`、`IconIds = { "lock", "down", "up", "shield", "mark", "clock", "heart", "star" }`。
3. `ContentDb.Validate()` 增加检查（中文错误信息带出错的 id）：特效、图标名必须在上面的列表里；`streamers`/`skillFx`/`statusIcons` 引用的 id 必须存在；路径只能是相对路径，不得含 `..`、`:`、`\`、`http`；`accent` 必须是 `#RRGGBB`。`Tools/PackCheck` 同步输出这些错误。
4. 四个现有内容包**不需要**加 `art`（全部走默认）；`docs/examples/example_pack.json` 如果存在，加一段示例 `art`。

## 不要做
