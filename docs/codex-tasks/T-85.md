# T-85 电脑对手强度回归检查

依赖：T-35、T-38（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
防止以后改规则或改电脑时，不小心把电脑变弱（或让难度顺序颠倒）。

## 要做的
1. 新文件 `Core/AiRegression.cs`：`public static AiLadderResult Run(ContentDb db, int games, uint seed)`：Easy/Normal/Hard/Expert 两两对战各 `games` 局（双方阵容随机但对称：每组阵容两边各打一次先后手），返回胜率矩阵。
2. 基准写进 `docs/ai-baseline.json`（当前代码跑出来的结果，original 包，每对 100 局，固定种子），以及允许的下降幅度（例如 5 个百分点）。
3. 规则：高难度对低难度胜率必须 > 50%；与基准相比下降超过允许幅度就失败。
4. `Tools/Ladder` 加 `--ai-regression` 输出表格；CI 不跑（太慢），但测试里跑一个小样本版本。

## 验收
自带测试 `Engine.Tests/T85_AiRegressionTests.cs`：小样本（每对 20 局）下难度顺序正确（Expert ≥ Hard > Normal > Easy 的胜率关系，允许 Expert 与 Hard 差距小于 5 个百分点时视为相等）；同样参数结果一致；基准文件能被读取且格式正确。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
