# T-75 联网对战断线重连

依赖：T-29、T-32（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
联网对战中一方短暂断线（例如网络抖动），重新连上后能继续这一局，而不是直接判负。

## 要做的
1. `NetSession` 支持重连：断线方用同一个会话标识（握手时由主机生成的随机串，**不包含任何账号信息**）重新连接，发送 `resume`（带已知的最后回合和 `StateHash`）；对方回复缺失的回合行动，断线方用回放补齐后比对哈希，一致则继续，不一致进入 `Desync`。
2. 断线期间对方状态为 `Waiting`，超过 60 秒（时间由调用方传入，便于测试）仍未重连则判掉线（`Error`）。
3. 承诺-揭示（T-32）在重连后仍然成立：已提交承诺的回合不能换行动。
4. `Tools/Cli` 联网模式在断线时提示「对方断线，等待重连（剩余 N 秒）」。

## 验收
自带测试 `Engine.Tests/T75_ReconnectTests.cs`：用 `LoopbackPair` 模拟中途断开再接上，整局打完双方哈希一致；超过时限判 `Error`；伪造的会话标识被拒绝；重连后试图更改已承诺的行动被拒绝。
