# T-108 专家难度的计算量上限（不卡画面）

依赖：T-35（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
专家难度的向前模拟在复杂局面可能算很久，画面会卡。给它加一个按「计算步数」而不是按时间的上限，保证结果仍然确定。

## 要做的
1. `AiWeights` 或新参数 `ExpertBudget`（默认值使 `Tools/Bench` 里最慢局面单步 < 200 毫秒），超出预算时用已经算完的部分里最好的行动。
2. 预算按模拟的节点数计算，不读系统时间，保证同一局面同一预算永远选同一行动（联网和回放需要）。
3. `Tools/Bench`（T-52）增加专家难度单步耗时统计（平均、最慢、P95），结果写进 PR。
4. 用 `Tools/Ladder` 跑新专家对旧专家（无预算）各 300 局，胜率下降不超过 3 个百分点；写进 PR。

## 验收
自带测试 `Engine.Tests/T108_ExpertBudgetTests.cs`：预算很小时仍返回合法行动；同一局面同一预算结果一致；预算越大节点数越多但不超过预算；默认预算下随机 20 个局面每步节点数都不超过预算。
