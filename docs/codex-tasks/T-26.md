# T-26 玩家档案（战绩统计）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
记录玩家在每个内容包里的战绩和常用主播，供以后的界面显示。只存在本机，不上传，不收集任何个人信息。

## 要做的
1. 新文件 `Core/Profile.cs`：
   - `public sealed class PackStats { public int Wins, Losses, Draws; public Dictionary<string,int> Picks, PickWins; }`
   - `public sealed class Profile { public Dictionary<string, PackStats> Packs; public void Record(Battle b, int playerSide); public string ToJson(); public static Profile FromJson(string json); }`
2. `Record`：对战没结束抛 `InvalidOperationException`；按 `b.Db.PackId` 记胜/负/平；玩家这一方出场名单（开局 6 位，含被禁的不算——如果 T-25 已合并，被禁的不计入）每人 `Picks +1`，赢了再 `PickWins +1`。
3. `ToJson` 输出稳定（键按字母排序），`FromJson` 用 `MiniJson`；空字符串或坏 JSON 返回空档案，不抛异常。
4. `Tools/Cli` 每局结束把档案存到 `--save-dir`（默认 `./saves/profile.json`）并打印本包战绩。
