# T-14 平衡调整

依赖：T-04（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
每个内容包里每位主播的出场胜率都在 40%～60% 之间。

## 要做的
1. 用 T-04 的模拟工具：`dotnet run --project Tools/Sim -- --pack <id> --games 5000 --seed 1`，对 `original`、`fan_asoul_vr`、`fan_holo_niji` 各跑一次，记录调整前的表。
2. **只改 JSON**（`StreamDuelRules.json` 的技能威力/PP/命中/效果参数，或内容包里主播的六项数值），不改引擎代码。每次改动幅度小（数值 ±10% 以内），反复模拟直到达标。
3. 同一套技能被多个内容包共用，改技能会同时影响所有包；优先改主播数值。
4. 现有测试依赖某些技能和数值（看 `Engine.Tests/`），改完必须全绿；测试因为数值变化而失败时，优先换一种改法，不要改测试。
5. 新文件 `docs/balance.md`：每个包调整前后的胜率表、改了哪些数值、为什么。

## 验收
`docs/balance.md` 里三个包调整后全部在 40%～60%。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
