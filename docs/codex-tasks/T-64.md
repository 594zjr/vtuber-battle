# T-64 对战房间流程（开房、设定、准备、开打、再来一局）

依赖：T-54、T-55（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
把「赛制 + 计时 + 禁用/首发 + 多局制」串成一个房间流程，联网对战和本地对电脑都走同一套状态机。

## 要做的
1. 新文件 `Core/MatchRoom.cs`（纯逻辑，不收发网络）：
   - `public enum RoomState { Setup, Ready, InGame, BetweenGames, Finished }`
   - `MatchRoom(ContentDb db, Ruleset ruleset, string hostName)`；`Join(string guestName)`（只能一位对手）；`SetRuleset(Ruleset r)`（只有房主、只在 Setup）；`SubmitTeam(int side, IList<string> team)` 返回中文错误列表（用 `Ruleset.CheckTeam`）；`SetReady(int side, bool ready)`（队伍不合法不能准备）。双方都准备好进入 Ready；`Start(uint seed)` 创建 `Match` 并返回第一局 `Battle`，进入 InGame。
   - `ReportGame(Battle b)`：转给 `Match.ReportResult`；没结束进入 BetweenGames（多局制允许换首发但不能换队伍），结束进入 Finished。`NextGame()` 开下一局。
   - `Rematch()`：Finished 后回到 Setup，保留双方队伍和赛制，准备状态清空。
   - `TurnClock Clock`：按 `Ruleset` 里的计时设置创建（没有计时设置则为 null）。
2. 对电脑：`MatchRoom.VsAi(ContentDb db, Ruleset r, string playerName, AiLevel level, uint seed)` 直接生成对手队伍（`TeamBuilder.Suggest`）并让电脑方自动准备。
3. 如果 T-29 的 `NetSession` 能直接接上，在 PR 里写出接法；不要求本任务改 `NetSession`。
