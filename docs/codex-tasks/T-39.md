# T-39 自动组队建议

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
“随机挑选”换成有道理的组队：合法、赛道分散、互相补位。

## 要做的
1. 新文件 `Core/TeamBuilder.cs`：`public static List<string> Suggest(ContentDb db, string seasonId, IList<string> fixedIds, uint seed)`。
   - 返回 6 个不重复的 id，前面依次是 `fixedIds`，其余补满。
   - 结果必须通过 `TeamCheck.Validate(db, seasonId, team)`；`fixedIds` 本身就违规（禁用、超出限制池、重复、不存在）时抛 `InvalidOperationException`，信息直接用 `TeamCheck` 的中文错误。
   - 打分：主赛道尽量不重复（名单够的话至少 5 个不同赛道）、对全包每位主播的平均对位分高、速度和耐久有高有低；用 `seed` 初始化的独立 `Rng`（引擎的 `Rng` 类）在高分候选里挑，结果可复现。
   - 名单不足 12 人的小包也能用。
2. Unity 画面里“随机挑选”按钮改用 `TeamBuilder.Suggest`（只改调用，种子用当前时间）；`Tools/Cli` 不给 `--team` 时用它。
