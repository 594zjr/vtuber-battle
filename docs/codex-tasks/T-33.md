# T-33 电脑对手权重可配置 + 自动调参工具

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
把普通难度电脑里写死的数字（各种加分、换人阈值、随机扰动幅度等）抽出来，可以保存、比较、自动调。

## 要做的
1. 新文件 `Core/AiWeights.cs`：`public sealed class AiWeights`，包含 `Ai.cs` 普通难度用到的**全部**常数（至少 8 个，起清楚的英文名，并写中文注释说明用途）。
   - `static AiWeights Default`（与现在的数值完全一致）、`Copy()`、`IEnumerable<string> Names()`、`double Get(string)`、`void Set(string, double)`（未知名字抛 `KeyNotFoundException`）、`ToJson()`、`static FromJson(string)`。
2. `Ai.Choose(Battle b, int s, AiLevel level, AiWeights w)`：普通难度用 `w`；其他难度可以忽略 `w`。原有的 `Choose(b, s)` 和 `Choose(b, s, level)` 行为**完全不变**（等价于传 `Default`）。
3. `Tools/Sim` 加 `--tune --rounds 20 --games 400 --seed 1`：随机扰动权重（每次只改 1～3 个，±30%），和当前最好的一组对打，胜率 > 55% 就替换；最后输出最好的权重 JSON 和对 `Default` 的胜率。不需要自动采用结果。
4. 把调出来的一组写进 `docs/ai_weights.md`（附胜率）。**不要**修改 `Default`。
