# T-31 联网对战：本机/局域网 TCP 与命令行

依赖：T-29（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
两台电脑（或同一台电脑的两个窗口）用命令行版联网对战。联网相关代码放 `Core/Net/`，命名空间仍是 `StreamDuel.Core`；只用 .NET Standard 2.1（Unity 也要能编译），不引入 NuGet 包。

## 要做的
1. `Core/Net/TcpTransport.cs`：`public sealed class TcpTransport : INetTransport, IDisposable`，按行（`\n`）收发 UTF-8；后台线程读、`TryReceive` 不阻塞。
   - `public static TcpHost Listen(int port, out int actualPort)`（port 为 0 时由系统分配）；`TcpHost : IDisposable` 有 `TcpTransport Accept(int timeoutMs)`（超时返回 null）。
   - `public static TcpTransport Connect(string host, int port, int timeoutMs)`（失败抛异常，信息为中文）。
   - 对方断开时 `NetSession` 进入 `Error`（“对方已断开”）。
2. `Tools/Cli` 加 `--host <端口>` 和 `--join <地址:端口>`：联网时双方各自用自己的 `--team`，用 T-17 的界面选行动；每回合显示“等待对手……”。
3. README 加“联网对战（命令行）”一节，写明只在可信的局域网使用、没有加密、没有账号。
4. **不做**：服务器、匹配、NAT 穿透、加密。
