# T-68 程序动画播放器：出场、受击、跳字、倒下、换人（需要本机有 Unity）

依赖：T-59、T-60（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
实现 `IBattleAnimator`：按 T-60 的时间线在 `BattleStage` 上播放程序动画。不需要任何美术资源。

## 要做的（只改 `Game/Anim/`）
1. `TimelineAnimator : IBattleAnimator`：按 `AnimCue.Start` 调度（用 `Time.unscaledDeltaTime` 推进），同一时刻的提示并行播放；`SkipToEnd()` 立即显示终态。
2. 每种提示的效果（只改 `style.translate`/`scale`/`opacity`/颜色，用简单缓动函数，自己写在 `Game/Anim/Easing.cs`）：
   - Enter：上场位从屏幕外滑入 + 淡入；SwitchOut：滑出淡出；SwitchIn：换上新头像后滑入。
   - Cast：施放方轻微前冲再回位；Projectile：交给 `IFxPlayer.Play(db.Art.SkillFx(id), 施放方, 目标方, duration)`（没有 T-69 时用 `NullFx`）。
   - Hit：受击方左右抖动 3 次；Flash：头像闪白（叠一层白色、透明度从 0.8 到 0）。
   - FloatText：在 `float-layer` 上从受击方头顶向上飘并淡出，颜色按 Style（伤害红、回复绿、暴击金色加大、未命中灰、能力升蓝降紫、状态白）。
   - HpBar：人气条从旧值平滑到新值，后面跟一条延迟的浅色残影条。
   - Faint：头像变灰、下沉、淡出。
   - StatusIcon：状态行里图标弹出（缩放 0→1.2→1）或缩小消失；图标用 `IStatusIconProvider`（没有 T-69 时用文字图标）。
   - FieldBanner：场地横幅从上方滑入、停留、滑出，文字为效果名。
3. 在主菜单加一个「动画预览」开发入口（新界面放 `Game/Screens/AnimPreview/`）：用固定种子打一局，逐回合播放，可切换 0.5/1/2 倍速和跳过。

## 不要做
- 不改 Core、不改对战界面布局（T-67）；不做技能特效图形本身（T-69）。

## Unity 任务的共同规则
- **本机没有安装 Unity 就不要领这个任务**（跳过它领下一个）。不要自己安装 Unity。
- 在自己的工作树 `D:\vtuber-battle-wt\T-xx` 里用 Unity Hub 打开 `UnityProject/`（第一次导入较慢，正常）；做完关闭这个 Unity 窗口，省内存。不要打开别的工作树或 `D:\vtuber-battle` 主目录的工程。
- 只改本任务列出的文件夹；需要改共享文件（`GameBoot.cs`、`ProjectSettings/`、`Packages/manifest.json`、T-59 的接口文件）时改动尽量小，并在 PR 描述里逐条说明。
- 画面层只调用 Core 的公开接口（`BattleViewModel`、`Battle.Events`、`BattleTimeline` 等），**不在画面里算任何规则**。
- **素材禁令**：不使用任何官方立绘、截图、Live2D、3D 模型、音频、Logo；不使用来源不明的图片或字体。头像、特效、图标全部用代码生成的占位（色块、几何图形、名字首字），或按内容包路径加载用户以后自己放进去的图片；仓库里不提交任何头像图片。
- 立绘和动画资源一律按内容包路径加载、可以替换（路径约定见 T-61）；以后换成手绘图或 Live2D 只换资源和一个实现类，不改对战界面代码。
- 验收截图贴在 PR 描述或评论里，不要提交进仓库。PR 里写 Unity 版本。
