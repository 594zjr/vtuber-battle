# T-35 电脑难度：专家（向前模拟）

依赖：T-12、T-34（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
最强的电脑：在拷贝上试打一回合再决定。

## 要做的
1. `AiLevel` 加 `Expert`；实现放新文件 `Core/Ai.Expert.cs`；`ChooseReplacement(b, s, Expert)` 也要实现（可以用拷贝试每个补位人选）。
2. 思路：对本方每个合法行动，在 `b.Clone()` 上假设对手按困难难度出招（可再加 1～2 个对手的备选），结算一回合；用局面评估（双方剩余人气比例、在播人数、能力等级、关键状态）打分，取期望最高的。可以对排名前几的再往后看一回合。
3. 只能在拷贝上模拟；真实对战只允许用 `b.Random()` 打破平局。
4. 性能：在 `dotnet test` 的机器上，单次决策平均不超过 50 毫秒（在 PR 里写实测值）。
5. `Tools/Cli`、`Tools/Sim` 支持 `--level expert`。
