## 背景
T-03、T-15 的 PR 里提出了三处规则空白，下面是定案，照此实现并写进 `docs/design.md`。

## 要做的
1. **PP 被削空**：一方在本回合选的技能，轮到它行动时如果 PP 已经是 0（比如被先手的 PP_REDUCE 削空），这次行动**失败**：不出招、不改用硬撑、不扣 PP，日志（该方的行动节点）写“……的「技能名」PP 已耗尽，行动失败”。回合开始时的 `Normalize` 不变。
2. **自伤下播**：行动者在自己技能结算过程中下播（无论来自 `pre` 效果、反噬还是其他自伤），这个技能余下的伤害和所有还没结算的效果全部跳过，日志写“……下播，技能中断”。之后照常进入补位流程。
3. **镜面回击的范围**：只反弹来自对手技能的直接伤害（含固定伤害）；持续伤害、反噬、自伤、状态结算伤害一律不反弹。当前实现已经这样做，只需在 design.md 5.2 的效果表里写明，并加一个测试覆盖“持续伤害不反弹”。
4. `docs/design.md` 3.4「一次行动内部」补上第 1、2 条。
