# T-121 本地赛事的每轮禁用环节

依赖：T-89（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
本地赛事里，每场开打前双方可以各禁用对方一位主播（类似正式比赛的禁选），让阵容更有变化。

## 要做的
1. 赛事创建时可选「每场禁用人数」（0、1、2，默认 0）。禁用沿用引擎现有的禁用机制（`Battle.Ban`），不另写一套规则。
2. 禁用顺序固定：先由种子顺位低的一方禁，再由另一方禁；电脑选手用现有电脑禁用逻辑（T-90 合并后自动用更聪明的版本）。
3. 禁用记录进入该场录像、赛事存档和 T-110 战报（「本场禁用：xxx、xxx」）。
4. `Tools/Cli` 赛事命令加 `--bans <0|1|2>`。

## 验收
自带测试 `Engine.Tests/T121_TournamentBanTests.cs`：禁用 0 时与原赛事结果逐局一致；禁用 1、2 时被禁主播不出场；禁用顺序符合规则；存档续赛后禁用不丢失；战报包含禁用记录。

1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
