# T-101 内容包下架开关

依赖：T-27（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
兑现同人作品「被要求即下架」的承诺：不改代码、不发新版，只改一个配置文件就能让某个内容包或某位主播从游戏里消失。

## 要做的
1. 新文件 `Resources/PackPolicy.json`：`{ "disabledPacks": [], "disabledStreamers": [], "reason": {} }`。
2. `PackLoader`（T-27）和内置包加载都读这个文件：被禁用的包不出现在包列表；被禁用的主播从所在包里移除（包里剩余主播少于 6 位时整包隐藏）；电脑陪练对手、队伍预设、队伍码里含被禁用主播时给出中文提示「该主播已下架」并不能使用。
3. 录像：含已下架主播的录像在 `Replay.Check`（T-93 已合并时）返回不能重放并说明原因；录像库列表里标记。
4. `FANWORK.md` 不改；在 `docs/design.md` 写明下架流程（改 `PackPolicy.json` → 推 main → 发布）。
5. `Tools/PackCheck` 显示当前下架状态。

## 验收
自带测试 `Engine.Tests/T101_PackPolicyTests.cs`：禁用一个包后列表里没有它；禁用某主播后该主播不能组队、电脑陪练和队伍码给出提示；剩余不足 6 位的包被隐藏；空策略文件时行为与原来完全一致。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
