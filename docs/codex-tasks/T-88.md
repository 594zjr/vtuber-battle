# T-88 对战解说词

依赖：T-40、T-42（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战时在画面角落滚动显示一句话解说（例如「暴击！这一下直接打掉一半人气」），让对战更有直播感。

## 要做的
1. 新文件 `Core/View/Commentary.cs`：`public static List<CommentLine> For(Battle b, int fromEvent, int toEvent)`；`CommentLine { int EventIndex; string Text; int Priority; }`。
2. 至少 40 条原创解说模板，放在 `Resources/Locale/zh-CN.json`（键名 `comment.*`），覆盖：开场、暴击、未命中、克制、被克制、击倒、残血反杀、连续击倒、控制成功、解除控制、换人、直播间效果生效、最后一位上场、胜利、平局。模板里可以用主播名、技能名、数值占位符。
3. 选择规则确定性：同一事件序列永远选同一条模板（用事件下标等计算，不用随机数、不消耗 `Battle.Rng`）；同一回合最多 2 条，优先级高的优先。
4. 文案要求：积极、有趣、不嘲讽玩家；不出现真实主播的梗、中之人话题或任何负面、擦边内容；不出现赛尔号文本。同人包主播同样只用名字和技能名，不加人设之外的描述。
5. `Tools/Cli` 显示解说行。

## 验收
自带测试 `Engine.Tests/T88_CommentaryTests.cs`：固定种子一局里至少出现开场、击倒、胜利三类解说；同输入同输出；每回合不超过 2 条；所有模板占位符都能被替换（结果里不含 `{`）；模板数 ≥ 40。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
