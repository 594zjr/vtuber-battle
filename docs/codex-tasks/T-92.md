# T-92 组队阶段的对位建议

依赖：T-77、T-39（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
双方公开阵容后（禁用、首发前），给玩家一句话建议：先上谁、禁谁、要小心谁。

## 要做的
1. 新文件 `Core/TeamAdvice.cs`：`public static TeamAdviceResult For(ContentDb db, IList<string> mine, IList<string> theirs)`；结果包括：`BanSuggestion`（建议禁用的对方主播 + 理由）、`LeadSuggestions`（我方首发前 2 名 + 理由）、`Threats`（对方对我方威胁最大的 2 位 + 被谁克制）、`Answers`（我方应对每个威胁的最佳人选）。
2. 基于 `DamageCalc.Matchup`（T-77）和赛道克制表；理由用中文、走 `Loc`。
3. 确定性；不使用随机数；不读取对方未公开的选择。
4. `Tools/Cli` 在禁用/首发阶段显示建议（`--advice`）。

## 验收
自带测试 `Engine.Tests/T92_TeamAdviceTests.cs`：构造的明显局面（对方一位克制我方多位）被列为威胁并被建议禁用；建议的首发都在我方队伍里；同输入同输出；理由文本非空、不含内部 id。
