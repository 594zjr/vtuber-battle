# T-102 本机对战数据统计

依赖：T-26、T-80（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
玩家可以看自己的对战数据：每位主播用了几次、胜率多少、常用阵容、对各难度电脑的战绩。（只统计对战，不做成就或奖励。）

## 要做的
1. 新文件 `Core/ProfileStats.cs`：从 `Profile`（T-26）和录像库（T-80）计算：`ByStreamer()`（出场次数、胜率、平均造成伤害、击倒数）、`TopTeams(n)`（最常用的阵容及胜率，阵容按主播 id 排序后视为同一阵容）、`VsAi()`（各难度胜/负/平）、`Recent(n)`（最近 n 局简表）、`Streaks()`（当前连胜/连败、最长连胜）。
2. 数据只来自本机，不上传；被下架的主播（T-101 已合并时）显示为「已下架」。
3. 性能：录像库 200 局时计算在 50 毫秒内（在 `Tools/Bench` 里加一项）。
4. `Tools/Cli` 加 `--stats`。

## 验收
自带测试 `Engine.Tests/T102_ProfileStatsTests.cs`：构造 20 局已知结果，各项统计数值正确；空数据时返回空结果不报错；阵容顺序不同视为同一阵容。
