# T-02 对战记录与回放

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
每局对战能存成一段 JSON 文本，以后原样重放，得到完全相同的战斗日志。

## 要做的
1. 新文件 `Core/Replay.cs`：
   - `public sealed class BattleRecord`：`Seed`(uint)、`PackId`(string)、`Teams`(两个 id 列表)、`Events`(按发生顺序：回合事件含双方原始行动 a0、a1；补位事件含 side、to)。
   - `public string ToJson()` 和 `public static BattleRecord FromJson(string json)`。读用现有的 `MiniJson.Parse`；写自己拼字符串，字符串要正确转义。行动用 `{"t":"Skill","i":2}` 这种形式（t 为 ActionType 名称）。
   - `public static class Replay` 的 `public static Battle Run(ContentDb db, BattleRecord r)`：`r.PackId != db.PackId` 时抛异常；否则用同样的种子、队伍和双方名字（"你"、"对手"）新建对战，按事件依次调用 `ResolveTurn` / `Replace`，返回这场对战。
2. `Core/Battle.cs`：增加只读属性 `public BattleRecord Record`，在构造函数里初始化（种子、内容包 id、队伍），在 `ResolveTurn` 里记录**纠正之前**的原始行动（重放时同样会经过 `Normalize`），在 `Replace` 里记录补位。尽量把新代码放进新的 partial 文件，少改原文件。
