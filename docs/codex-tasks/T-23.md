## 目标
一局打完能看到每位主播打了多少伤害、击倒几个、用了哪些技能，供结算页、模拟工具和命令行使用。

## 要做的
1. 新文件 `Core/BattleSummary.cs`：
   - `public sealed class FighterStats { public string StreamerId; public int DamageDealt, DamageTaken, Kos, TurnsActive; public bool Fainted; public Dictionary<string,int> SkillUses; }`
   - `public sealed class BattleSummary { public List<FighterStats>[] Sides; public static BattleSummary From(Battle b); public string ToText(); }`，`Sides[s][i]` 对应 `b.Sides[s].Team[i]`。
2. 计数规则：
   - `DamageTaken`：所有让人气减少的量（含持续伤害、反噬、固定伤害）。
   - `DamageDealt`：本方技能对对手造成的伤害（含固定伤害、镜面反弹），不含持续伤害。
   - `Kos`：每次有主播下播，记给**当时对方场上**的主播一次（无论下播原因）。
   - `TurnsActive`：每个回合结束节点时在场的主播 +1。
   - `SkillUses`：技能 id → 使用次数，每条 `Kind == "act"` 的日志对应一次（硬撑用 id `struggle` 记）。
   - 实现方式自定（在 `Battle` 里加计数器，或在 `From` 里根据日志算），但必须准确、可复现。
3. `ToText()`：中文表格，双方各 6 行。
4. `Tools/Sim` 的 CSV 增加每位主播平均造成伤害、平均击倒数两列；`Tools/Cli` 对战结束后打印 `ToText()`。
