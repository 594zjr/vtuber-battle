# T-54 赛制与多局制（三局两胜）

依赖：T-46（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战房间可以选赛制：休闲、排位（禁用 + 选首发 + 三局两胜）、自定义。

## 要做的
1. 新文件 `Core/Ruleset.cs`：`public sealed class Ruleset { public string Id, Name, Season; public bool BanOne, LeadPick; public int BestOf = 1; public List<string> Modifiers; public int TurnSeconds, BankSeconds; }`，`ToJson/FromJson`，`Validate(ContentDb db)`（`BestOf` 只能是 1/3/5，赛季和修饰器必须存在，否则抛 `KeyError`），`CheckTeam(ContentDb db, IList<string> team)`（调用 `TeamCheck.Validate`，带上赛季）。
2. `public static class Rulesets { public static IReadOnlyList<Ruleset> All; }`：至少 `casual`（休闲：一局，无禁用）、`ranked`（排位：禁用 + 选首发 + 三局两胜 + 计时）、`chaos`（乱斗：一局 + 2 个修饰器）。
3. `public sealed class Match`：构造 `(ContentDb db, Ruleset r, IList<string>[] teams, string[] names, uint seed)`；`StartNextGame()` 返回按赛制配置好的 `Battle`（每局种子由 `seed` 和局号推出，可复现）；`ReportResult(Battle finished)` 记胜负；`Wins`（`int[2]`）、`Draws`、`Over`（某方先赢满 `BestOf/2+1` 局，或打满 `BestOf` 局）；结束后再开局抛 `InvalidOperationException`。
4. `Tools/Cli` 加 `--ruleset <id>`。`docs/design.md` 加“赛制”一节。
