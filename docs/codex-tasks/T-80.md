# T-80 本地录像库

依赖：T-30（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
自动保存每一局的录像，可以按主播、胜负、日期筛选，超过上限自动清理最旧的。

## 要做的
1. 新文件 `Core/ReplayLibrary.cs`：`ReplayLibrary(string directory, int maxCount = 200)`；`string Save(BattleRecord r, BattleSummary s, string note = null)`（文件名用时间戳 + 种子，返回 id；时间由调用方传入或用可注入的时钟，便于测试）；`List<ReplayEntry> List(ReplayFilter f = null)`（`ReplayEntry`：Id、Date、PackId、双方名字、双方阵容、胜方、回合数、备注）；`BattleRecord Load(string id)`；`void Delete(string id)`；`void SetNote(string id, string note)`。
2. 索引文件 `index.json` 和录像分开存；索引损坏时能从录像文件重建；单个录像文件损坏时跳过并在 `List` 结果里标记，不崩溃。
3. 超过 `maxCount` 时删除最旧且没有备注的录像（有备注视为收藏，不自动删）。
4. 不保存任何账号、设备信息；路径只在给定目录内（拒绝 id 里的 `..`、`/`、`\`）。
5. `Tools/Cli` 对战结束自动保存，`--replays` 列出，`--replay <id>` 重放。

## 验收
自带测试 `Engine.Tests/T80_ReplayLibraryTests.cs`（用临时目录）：保存后能列出和读回并重放出同样结果；筛选正确；超上限删最旧但保留有备注的；索引损坏能重建；坏文件跳过；非法 id 被拒绝。
