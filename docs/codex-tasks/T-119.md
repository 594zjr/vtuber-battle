# T-119 排位赛季：赛季编号、软重置与历史段位

依赖：T-57（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
排位分（T-57）现在一直累计。加入赛季：新赛季开始时分数向 1500 靠拢，旧赛季的最终分数和段位留作纪念。

## 要做的
1. `Profile` 的排位记录增加 `Season`（整数，从 1 开始）和 `History`（每个已结束赛季的最终分数、最高分数、段位、场数）。
2. `RatingSystem.NewSeason(PlayerRating r)`：新分数 = `1500 + (旧分数 - 1500) / 2`（四舍五入规则同 §13），场数清零但保留「已定级」标记，使新赛季不再用 K=40（写进 design.md）。
3. 赛季切换由玩家或主机手动触发（本机没有服务器时间），`Tools/Cli` 加 `--new-season` 和 `--rating-history`。联网握手只交换当前赛季分数，不改协议版本。
4. 旧档案没有赛季字段时视为第 1 赛季、历史为空。

## 验收
自带测试 `Engine.Tests/T119_SeasonTests.cs`：软重置公式在高于、低于、等于 1500 时都正确；切换后历史记录完整；已定级玩家新赛季首局使用 K=24；旧档案读取后行为与 T-57 一致；JSON 往返不丢字段。
