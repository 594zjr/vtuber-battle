# T-41 给画面用的视图模型 BattleViewModel

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
把画面需要显示的东西一次性整理好，Unity 画面（以后的 UI Toolkit 版、IMGUI 版）都只读这个对象，不再各自拼规则。不需要 Unity。

## 要做的
1. 新文件 `Core/View/BattleViewModel.cs`（命名空间 `StreamDuel.Core`），`public static BattleViewModel From(Battle b, int viewerSide)`，纯数据（只有字段和列表，没有对 Battle 的引用）：
   - `Turn`、`Phase`、`Notice`（同人包的声明，原创包为空）、`Sides[2]`：`Name`、`Active`、`Team[6]`（`Id, Name, Tracks（显示用，双赛道用“/”）, Hp, MaxHp, Pct, Fainted, Persona 名与说明, Stages 字典, Statuses 列表`）。
   - 状态芯片 `ChipView { Id, Name, IsStatus, Turns, Stacks, Tooltip }`：状态和直播间效果都放进 `Statuses`，`IsStatus` 区分；`Tooltip` 用 `Describe` 生成，写明类别、剩余回合、能否被消除。
   - `Skills`（viewerSide 场上主播的 5 个技能）：`Index, Id, Name, Track, Category, Power, Pp, MaxPp, Priority（含先制修正，等于 LegalFor 里的值）, Usable, Fifth, Effectiveness（对对手场上主播的克制倍率）, DamageMin/Max（用 PreviewDamage）, Effects（每个效果 Timing=“命中前/命中后”、Text、Dispel）`。
   - `SwitchTargets`：可换上场的队友下标（等于 `LegalFor(viewerSide).Switches`）；`ControlledReason`（被控制时的说明）。
   - `NodeStrip`：本回合的 8 个节点名，以及每个节点在本回合日志里有没有内容。
2. 构建视图不能改变对战（`StateHash` 不变，不消耗随机数）。
3. IMGUI 的 `Game/BattleScreen.cs` 里技能按钮和状态芯片改为读 `BattleViewModel`（只改读取方式，界面外观不变）。
