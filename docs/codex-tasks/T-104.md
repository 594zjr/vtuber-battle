# T-104 混合内容包乱斗模式

依赖：T-27、T-19（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
新增一种对战玩法：从多个内容包里混合选人（例如原创主播对同人主播），或者双方随机分配阵容。

## 要做的
1. 新方法 `ContentDb.Merge(params ContentDb[] packs)`：合并多个包的主播、技能、人设、状态、直播间效果；规则（`StreamDuelRules.json`）只能有一份；id 冲突时给出中文错误（内容包自定义内容都有自己的前缀，正常不会冲突）；合并后的 `PackId` 为 `mix:` 加各包 id 排序拼接；`ContentHash` 覆盖全部包。
2. 同人包的声明（`notice`）在合并后仍然可以按主播查到（`db.NoticeFor(streamerId)`），画面要能显示。
3. 乱斗：`MixedBattle.RandomTeams(ContentDb merged, uint seed)` 给双方各随机 6 位（不重复，来自 `Rng`）；也可以手动组队。
4. 录像、联网（双方必须加载同样的包组合，`ContentHash` 校验）都支持。
5. `Tools/Cli` 加 `--packs original,fan_asoul_vr --random-teams`。

## 验收
自带测试 `Engine.Tests/T104_MixedPacksTests.cs`：两个包合并后主播数量正确、能打完整局；id 冲突给出中文错误；同人声明可按主播查到；随机阵容确定性；录像重放一致；包顺序不同合并结果哈希相同。
