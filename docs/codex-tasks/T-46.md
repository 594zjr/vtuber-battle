# T-46 规则修饰器（给闯关、每日挑战用）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
用少量开关改变对战规则，让闯关和每日挑战有变化。

## 要做的
1. `BattleOptions` 加 `List<string> Modifiers`（可为 null）。新文件 `Core/BattleModifiers.cs`：`public sealed class ModifierDef { public string Id, Name, Desc; }`，`public static IReadOnlyList<ModifierDef> All`。未知 id 在构造对战时抛 `KeyError`。
2. 至少实现这 6 个（名字和说明自己写中文）：
   - `half_pp`：双方所有技能 PP 上限减半（向上取整），当前 PP 同步。
   - `stage_cap_3`：能力等级上下限改为 ±3。
   - `sudden_death`：从第 10 回合（含）起，每个回合结束节点双方场上主播各失去 1/16 最大人气（向下取整，至少 1），日志写明。
   - `hype_start`：开局双方首发各获得 1 层「热度」（印记）。
   - `no_switch`：不能主动换人（补位不受影响）。
   - `hp_x2`：双方所有主播最大人气和当前人气 ×2。
3. 修饰器写入对战记录，`Replay.Run` 能还原；`StateHash` 包含修饰器列表。开场日志列出启用的修饰器。
4. `docs/design.md` 加一节“规则修饰器”。
