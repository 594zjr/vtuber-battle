# T-10 打击表现（需要本机有 Unity）

依赖：T-09（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
对战更有手感：人气条缓动、伤害/回复飘字、下播时头像变灰淡出、本回合先手方高亮、技能命中时卡片轻微抖动。

## 要做的
1. 只在 `Game/` 和 `UI/` 里实现，数据全部来自 `Battle.Log` 的每一行（Kind、Side、快照），不另算数值。
2. 设置里加“动画”开关；关闭时行为与现在完全一致。开“快速播放”时所有动画时长减半。
3. 不加任何音频文件（以后有自制音效再说）。

## 验收
录一段 10 秒以内的 GIF 或几张截图放在 PR 里。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过。
2. 本机 Unity 打开工程 Console 无红色报错、无黄色警告；按 Play 能完整打完一局。PR 里写 Unity 版本，附截图（存到 PR 评论或描述里，不要提交进仓库）。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
**本机没有安装 Unity 就不要领这个任务**（跳过它领下一个）。不要自己安装 Unity。
