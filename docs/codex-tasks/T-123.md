# T-123 自制立绘与特效资源的检查工具

依赖：T-61（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
以后用户或约稿画师把立绘放进内容包目录时，需要一个工具告诉他们：缺了谁、哪张尺寸或格式不对、哪张多余没被用到。

## 要做的
1. `Tools/PackCheck` 增加 `--art <包目录>`：按 T-61 的 `ArtManifest` 路径约定逐个检查每位主播的立绘和特效资源：缺失（画面会用占位，提示「将使用占位」）、格式不是 PNG、尺寸不在清单建议范围内、文件过大（阈值写进 design.md）、目录里有清单没引用的文件。
2. 只读取图片文件头得到宽高（PNG IHDR），不引入图片库，不修改任何文件。
3. 输出中文报告和 `--json`；有错误时退出码非 0，只有缺失时退出码为 0（缺失是允许的，会用占位）。
4. 提醒文字里重申：只放自己画的或有授权的图，不放官方立绘和截图（文字写进报告末尾）。

## 验收
自带测试 `Engine.Tests/T123_ArtCheckTests.cs`（临时目录里用代码生成的小 PNG）：缺失、格式错、尺寸错、过大、多余文件各被正确报告；全部正确时报告为「通过」；检查前后目录文件和修改时间不变；非 PNG 伪装成 .png 时报格式错。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
