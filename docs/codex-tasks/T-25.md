# T-25 开局禁用（各禁对方 1 位）

依赖：T-16（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
赛尔号巅峰式的开局禁用：双方看到对方 6 位后，各禁掉对方 1 位，剩 5 打 5。

## 要做的
1. 新类 `public sealed class BattleOptions { public uint? Seed; public bool LeadPick; public bool BanOne; }`，新构造函数 `Battle(ContentDb db, IList<string>[] teams, string[] names, BattleOptions opt)`。旧构造函数保留，行为不变（内部转成 options）。
2. `Phase` 加 `Ban`。`BanOne` 为 true 时对战从 `Phase.Ban` 开始；`ChooseBan(int side, int foeIndex)` 记下禁用（重复调用或越界抛 `InvalidOperationException`/`ArgumentOutOfRangeException`）；双方都禁完后，从各自队伍里移除被禁的主播（其余顺序不变，1 号位被禁则原 2 号位成为首发），写开场节点日志“……禁用了……”，然后进入 `Lead`（若启用）或 `Choose`。
3. `Ai.ChooseBan(Battle b, int s)`：禁掉对我方整队威胁最大的那位（用现有对位分思路），只用 `b.Random()` 打破平局。
4. 回放：`BattleRecord` 记录 `BanOne` 和禁用事件，`Replay.Run` 能完整重放。旧记录（没有这些字段）照常可读。
5. `Tools/Cli` 加 `--ban`。`docs/design.md` 第 2 节补“开局禁用”。
