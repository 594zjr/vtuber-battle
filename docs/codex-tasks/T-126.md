# T-126 接手对局与原录像的结局对照

依赖：T-116、T-74（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
从录像某回合接手打完后（T-116），玩家想知道「我的选择比原来好吗」。把两条结局放在一起对照。

## 要做的
1. 新文件 `Core/BranchCompare.cs`：输入原录像和接手后的录像（录像里已有来源信息），输出：接手回合、两边的胜负结果、结束时双方剩余人数和总血量百分比、结束回合数、接手后各自的关键回合（复用 T-74 的复盘）。
2. 给出一句中文结论，例如「接手后提前 3 回合获胜」「结果相同」「原录像获胜，接手后落败」。
3. 接手录像的来源与给定原录像不符时给出中文错误。
4. `Tools/Cli` 加 `--branch-compare <原录像> <接手录像>`。

## 验收
自带测试 `Engine.Tests/T126_BranchCompareTests.cs`：同样操作接手时结论为「结果相同」；改变选择后结局差异被正确报告；来源不符报错；关键回合与直接调用 T-74 复盘结果一致；不修改输入录像。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
