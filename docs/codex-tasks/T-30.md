# T-30 内容指纹与带版本的对战记录

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
回放和联网都要确认双方用的是同一份内容（规则 + 内容包）。

## 要做的
1. `ContentDb.ContentHash()`：返回 16 位小写十六进制（FNV-1a 64 位），对规则和内容包里**所有影响对战的数据**（赛道、克制表、状态、直播间效果、人设、技能、主播，以及包 id）按 id 排序后写入；显示用文字（名字、说明、blurb）也算进去。同一份数据多次加载结果相同；任何数值改动都会改变结果。不得用 `GetHashCode`。
2. `BattleRecord` 增加 `Version`（新记录为 2，读到没有 `version` 字段的旧记录为 1）和 `ContentHash`（新记录写入对战用的内容指纹）。
3. `Replay.Run`：记录里有 `ContentHash` 且与当前 `db.ContentHash()` 不同 → 抛 `InvalidOperationException("内容不一致：……")`；旧记录没有指纹时照常重放。
4. 如果 T-29 已合并：`hello` 消息带上内容指纹，不一致时报错；没合并就在 PR 里写明，留给审查员。
5. `Tools/PackCheck` 打印每个包的内容指纹。
