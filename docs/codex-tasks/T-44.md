# T-44 闯关模式（规则层）+ 原创包 8 关

依赖：T-46（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
单人闯关：一关一关打电脑，赢了解锁下一关。这次做规则、数据和命令行入口，Unity 画面以后再做。

## 要做的
1. 内容包可选字段 `campaigns`：`{"main": {"name": "...", "stages": [ { "name": "...", "intro": "开场白", "enemy": [6 个主播 id], "ai": "easy|normal|hard|expert", "modifiers": ["..."], "enemyName": "..." } ] } }`。`ContentDb.Campaigns`（字典），校验 id、AI 难度、修饰器（T-46 的 `BattleModifiers`）都合法。
2. 新文件 `Core/Campaign.cs`：
   - `CampaignProgress`（每个包每个闯关已通过的关卡集合；`ToJson/FromJson`）。
   - `CampaignRunner.IsUnlocked(db, progress, campaignId, stage)`（第 0 关总是解锁，之后需要通过前一关）。
   - `CampaignRunner.Start(ContentDb db, string campaignId, int stage, IList<string> playerTeam, uint seed, CampaignProgress progress = null)`：返回按关卡设置（敌方阵容、AI 难度由调用方读取、修饰器、敌方名字）创建好的 `Battle`，玩家是 side 0。关卡下标越界、关卡未解锁（`progress` 为 null 时视为全新存档，只有第 0 关解锁）、队伍不合法时抛 `InvalidOperationException`（信息中文）。
   - `CampaignRunner.Complete(db, progress, campaignId, stage, Battle finished)`：玩家（side 0）获胜才记为通过。
3. 在 `original.json` 里加 `main` 闯关 8 关：敌人阵容逐步变强，前 2 关 `easy`，最后 2 关 `hard`/`expert`；每关一句开场白（≤ 40 字），敌方名字是原创的对手主播团体名。**文案禁区**：全部原创中文；不得出现赛尔号（淘米）的任何名字或文本；不写现实事件、真人隐私、擦边、贬损、政治宗教内容；涉及同人包主播时只用公开艺名和公开、正面的人设。
4. `Tools/Cli` 加 `--campaign main`：列出关卡与解锁情况，选关后对战，结束后保存进度（用 T-43 的存档，如果已合并；否则存 `--save-dir/campaign.json`）。
