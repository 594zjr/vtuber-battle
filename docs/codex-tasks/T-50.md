# T-50 成就（规则层）

依赖：T-23、T-26（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
给玩家一些小目标。这次做定义和判定，Unity 画面以后显示。只存本机。

## 要做的
1. 新文件 `Core/Achievements.cs`：
   - `public sealed class AchievementDef { public string Id, Name, Desc; public bool Hidden; }`；`public static IReadOnlyList<AchievementDef> All`（至少 20 个，id 小写英文）。
   - `public sealed class AchievementState`（已解锁的 id 与解锁时的回合数/对战种子；`ToJson/FromJson`，坏 JSON 返回空）。
   - `public static List<AchievementDef> Evaluate(AchievementState st, Battle finished, int playerSide, Profile profile)`：返回**本次新解锁**的成就并写入 `st`。只根据对战结果、`BattleSummary`、`Profile` 判断，结果可复现。
2. 必须有：`first_win`（第一次获胜）、零下播获胜、一回合内击倒、用第五技能完成击倒、逆转（场上只剩 1 位时获胜）、靠状态持续伤害击倒、累计 10/50/100 胜（读 `Profile`）、每个内容包各赢一次、用满 6 种赛道的阵容获胜等。
3. 名字和说明原创、轻松。**文案禁区**：全部原创中文；不得出现赛尔号（淘米）的任何名字或文本；不写现实事件、真人隐私、擦边、贬损、政治宗教内容；涉及同人包主播时只用公开艺名和公开、正面的人设。
4. `Tools/Cli` 每局结束后打印新解锁的成就，存进存档。
