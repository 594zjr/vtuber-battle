# T-55 对战计时（每回合限时 + 总时间）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
联网和排位需要计时：每回合有基本时间，超出部分从总时间里扣，总时间用完就自动出招。

## 要做的
1. 新文件 `Core/TurnClock.cs`：`TurnClock(double turnSeconds, double bankSeconds)`；`StartTurn()`（双方回合时间重置、清除已提交）；`bool Tick(int side, double seconds)`（推进该方的时间：先扣回合时间，用完再扣总时间；该方已提交时不计时；返回该方是否刚刚或已经超时）；`Submit(int side)`；`TurnLeft(side)`、`BankLeft(side)`、`TimedOut(side)`。不读系统时钟，时间由调用方传入（便于测试和联网同步）。
2. `static BattleAction TimeoutAction(Battle b, int side)`：超时默认“跳过”（被控制时同样跳过）；`static int TimeoutReplacement(Battle b, int side)`：补位超时选编号最小的可上场队友。
3. 如果 T-29 已合并：`NetSession` 可选启用计时（主机在 hello 里声明秒数），超时由**超时方自己**提交默认行动；对方在总时间用完后再多等 10 秒仍未收到时判对方掉线（`Error`）。没合并就写在 PR 里留给审查员。
4. `Tools/Cli` 加 `--timer 10,30`（显示倒计时，超时自动出招）。
