依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
为以后的排位对战准备计分规则（先在本机记录，以后服务器复用同一套代码）。

## 要做的
1. 新文件 `Core/Rating.cs`：`PlayerRating { int Rating = 1500; int Games; ToJson; FromJson }`；`RatingSystem.Apply(PlayerRating a, PlayerRating b, double scoreA)`（1 胜 / 0.5 平 / 0 负；Elo，前 10 局 K=40，之后 K=24；结果四舍五入为整数；两人都在 10 局以后时总分不变）。
2. 段位表 `RatingSystem.Tiers`（至少 5 档，原创中文名，例如“新人主播、人气主播、当红主播、顶流主播、传说主播”，每档有 `Name`、`MinRating`，从 0 开始升序）；`TierOf(int rating)`。
3. 如果 T-26 已合并，`Profile` 增加每个赛制（T-54，若已合并；否则“默认”）的 `PlayerRating`，联网对战结束时双方各自按结果更新本机记录（不做防作弊，在注释里写明只用于本机显示）。
4. `docs/design.md` 加“排位分”一节。
