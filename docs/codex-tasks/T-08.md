# T-08 在 Unity 里打开工程、清零报错、出 Windows 包（需要本机有 Unity）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
工程在真实 Unity 里第一次打开就干净，能打出 Windows 可执行包。

## 要做的
1. 用本机已安装的 Unity 6（6000.x）打开 `UnityProject/`。把 `ProjectSettings/ProjectVersion.txt` 对齐到实际版本。
2. 清掉 Console 里所有报错和警告（只改 `Assets/StreamDuel/Game/`、`ProjectSettings/`、`Packages/`；Core 有问题在 PR 里说明）。
3. 新建 `Assets/Scenes/Main.unity`（空场景，`GameBoot` 会自动创建画面），加入 Build Settings 第 0 位。
4. 新文件 `Assets/StreamDuel/Editor/BuildScript.cs`：`public static void BuildWindows()` 把游戏打到 `Build/Windows/StreamDuel.exe`；`.gitignore` 加 `Build/`。命令行用法写进 README：`Unity.exe -batchmode -quit -projectPath UnityProject -executeMethod BuildScript.BuildWindows -logFile build.log`。
5. 实际打一次包并运行，打完一局。

## 验收
截图：组队页、对战中、结束弹窗、Console 无红黄。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过。
2. 本机 Unity 打开工程 Console 无红色报错、无黄色警告；按 Play 能完整打完一局。PR 里写 Unity 版本，附截图（存到 PR 评论或描述里，不要提交进仓库）。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
**本机没有安装 Unity 就不要领这个任务**（跳过它领下一个）。不要自己安装 Unity。
