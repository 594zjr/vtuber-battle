# T-112 两份录像的分歧点对比

依赖：T-80、T-30（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
排查电脑对手或联网不同步问题时，需要知道两份录像（同一开局、不同版本或不同选择）从哪一回合开始不一样。

## 要做的
1. 新文件 `Core/ReplayDiff.cs`：`ReplayDiff.Compare(ContentDb db, Replay a, Replay b)` 逐回合重放两份录像，返回：开局是否相同（内容包、种子、双方队伍）、第一处行动不同的回合、第一处状态哈希不同的回合（行动相同但结果不同说明引擎或内容有变化）、该回合双方血量、能力等级、状态和直播间效果的差异列表。
2. 开局不同时直接说明哪一项不同，不继续逐回合比较。
3. 只读：不修改录像；内容包缺失或录像版本不支持时沿用现有中文错误。
4. `Tools/Cli` 加 `--replay-diff <录像1> <录像2>`，中文逐项输出。

## 验收
自带测试 `Engine.Tests/T112_ReplayDiffTests.cs`：同一录像自比无差异；在第 N 回合改一个行动后报出分歧回合为 N 且差异列表非空；改种子时报「开局不同：种子」；两份录像长度不同时正确报出较短一份结束的位置；不修改输入对象。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
