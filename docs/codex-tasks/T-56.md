# T-56 队伍预设与导入导出码

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
玩家可以保存多套队伍，并用一串短码分享给别人。

## 要做的
1. 新文件 `Core/TeamPreset.cs`：`TeamPreset { Name, PackId, List<string> Ids }`，`Check(ContentDb db, string seasonId)`（包 id 不同时报“这套队伍属于其他内容包”，再加上 `TeamCheck.Validate` 的错误）；`TeamPresetList { List<TeamPreset> Items; ToJson; FromJson（坏 JSON 返回空） }`。
2. `TeamCode.Encode/Decode`：`SDT1-` + base64url（无填充）的紧凑数据 + 校验；忽略空白；坏码抛 `FormatException`。普通队伍的码 < 200 字符。
3. 如果 T-43 已合并，`FileSaveStore` 增加 `SaveTeams/LoadTeams`（`teams.json`）；否则只做 Core 类。
4. `Tools/Cli` 加 `--team-code <码>`（用这套队伍开打）和 `--export-team`（打印当前队伍的码）。
