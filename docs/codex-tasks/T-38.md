# T-38 天梯模拟工具：主播与阵容强度榜

依赖：T-23（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
比 T-04 的单人胜率更进一步：看哪些**阵容组合**强，给平衡和电脑组队参考。

## 要做的
1. 新命令行工程 `Tools/Ladder/Ladder.csproj`（net8.0，引用 Engine）：`dotnet run --project Tools/Ladder -- --pack original --teams 64 --rounds 10 --seed 1 [--level normal|hard] [--season s1]`。
2. 用 `--seed` 决定的 `System.Random` 生成指定数量的合法阵容（遵守赛季规则；如果 T-39 已合并，用 `TeamBuilder` 生成一半、随机生成一半）；瑞士轮，每轮按积分配对，每对打两局（交换先后/种子）。
3. 计算每个阵容的 Elo（初始 1500，K=24），以及每位主播的“出场加权 Elo”。输出两个 CSV 到 `--out` 文件夹（默认 `./ladder_out`）：`teams.csv`、`streamers.csv`，并在控制台打印前 10 名。
4. 同样参数两次运行输出完全一致。README 加一行用法。

## 验收
两次运行输出一致；`--teams 16 --rounds 3` 在一分钟内跑完。
