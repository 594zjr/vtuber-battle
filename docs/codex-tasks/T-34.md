# T-34 对战深拷贝 Battle.Clone()

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
电脑对手要“在脑子里试打”，需要一份可以随便改、不影响真实对战的拷贝。

## 要做的
1. `Battle.Clone()`（新文件 `Core/Battle.Clone.cs`）：深拷贝所有可变状态：双方队伍、每位主播（人气、下播、技能与 PP、能力等级、状态、直播间效果、LastSkillIndex 以及人设用到的任何内部计数）、阶段、回合、Need、Winner、Rng 状态、首发/禁用进度、日志（拷贝列表，`LogEntry` 可以共享或复制，但往拷贝里追加日志不能影响原对战）、记录 `Record`（深拷贝）。`Db` 共享。
2. 写一段注释列出所有字段，并在 `Battle` 新增字段时提醒同步（例如在 `Battle.Clone.cs` 顶部注释）。
3. 拷贝之后，对两者执行同样的操作，`StateHash()` 必须始终一致。
