# T-73 新效果码：能力交换、复制强化、延迟伤害、恢复 PP

依赖：T-18（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
补四种常见的对战机制，给后续内容包用。

## 要做的
1. 新效果码（`Battle.Effects2.cs` 或新文件；`docs/design.md` 效果码表、`Describe.cs` 说明同步更新；每个都必须有 `at: pre/post` 和驱散规则）：
   - `STAGE_SWAP`：与目标交换全部能力等级变化。
   - `STAGE_COPY`：复制目标当前的正向能力等级变化（负向不复制），不超过上限。
   - `DELAYED_DAMAGE`（参数 `turns`、`n`）：给目标挂一个回合类直播间效果，`turns` 回合后的回合结束节点造成 n 点固定伤害；目标下场则效果消失；可被消回合效果清除。
   - `PP_RESTORE`（参数 `n`）：自己所有技能（不含第五技能）PP 各恢复 n，不超过上限。
2. 每个效果在日志里写清节点和数值，并产生对应的 `BattleEvent`（T-40）。
3. `original.json` 不改；在 `docs/examples/` 或测试里用包内自定义技能演示。

## 验收
自带测试 `Engine.Tests/T73_NewEffectCodes2Tests.cs`：四个效果各至少两个用例（正常、边界：上限、对方已下场、被驱散、PP 已满），全部确定性（固定种子）。
