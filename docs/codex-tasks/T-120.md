# T-120 两位主播并排对比

依赖：T-113、T-77（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
组队时想比较两位主播谁更适合。并排显示两张资料卡（T-113），并给出两人互相对打时每个技能的伤害范围。

## 要做的
1. 新文件 `Core/View/StreamerCompare.cs`：`StreamerCompare.Build(ContentDb db, string a, string b)` 返回两人的六维数值对比（标出谁高）、赛道克制关系（谁克谁、倍率）、先制技能对比，以及用 `DamageCalc.Range` 算出的 A 每个技能打 B、B 每个技能打 A 的伤害范围和「几下能击倒」（按满血、无能力等级变化）。
2. `ToText` 生成中文纯文本；只用内容包数据和现有说明生成器，不添加任何人物设定文字。
3. 两人来自不同内容包时（混合乱斗 T-104），按混合规则处理并标明各自来源包。
4. `Tools/Cli` 加 `--compare <主播id> <主播id>`。

## 验收
自带测试 `Engine.Tests/T120_CompareTests.cs`：伤害范围与直接调用 `DamageCalc.Range` 一致；数值高低标记正确；同一主播自比时双方一致；不同包主播可对比并标明来源；不存在的 id 给中文错误。
