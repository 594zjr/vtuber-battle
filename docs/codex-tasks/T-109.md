# T-109 色弱友好的赛道配色与图形标记

依赖：T-22（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
赛道（类型）只靠颜色区分时，色弱玩家很难分清。给每个赛道加一个图形符号，并提供色弱友好配色。

## 要做的
1. `StreamDuelRules.json` 的每个赛道增加 `symbol`（一个简单的字符或图形名，例如 ♪ ★ ◆ ● ▲ ■ 等，写进 design.md）和 `colorAlt`（色弱友好配色）；`TypeDef` 读取这两个字段（缺省时有默认值）。
2. `GameSettings`（T-43）增加 `ColorblindMode`；`BattleViewModel` 输出赛道时同时给出符号和当前模式下的颜色（画面任务直接用）。
3. 新测试辅助：计算颜色对比度；所有 `colorAlt` 两两之间在常见三种色弱模拟（红色弱、绿色弱、蓝色弱）下的差异足够大（写出判定阈值）；符号两两不同。
4. 不改任何数值和规则。

## 验收
自带测试 `Engine.Tests/T109_ColorblindTests.cs`：每个赛道都有不同的符号；色弱模式下视图模型给出 `colorAlt`；三种色弱模拟下任意两赛道颜色差异超过阈值；默认模式下与原来颜色一致。
