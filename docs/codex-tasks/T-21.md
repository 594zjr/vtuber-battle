# T-21 5 个新人设代码

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
人设（相当于赛尔号的魂印）再多 5 种写法，给以后的主播用。

## 要做的
在 `Core/Persona.cs`（或新文件 `Core/Persona2.cs`）实现，`docs/design.md` 6.2 人设代码表加 5 行，`Describe.cs` 能显示说明，电脑对手 `Ai.cs` 至少不因此出错：

| 代码 | 参数 | 节点 | 效果 |
|---|---|---|---|
| `T_KO_HEAL` | `frac` | 击倒对手后 | 自己回复 floor(最大人气 × frac)，不超过上限 |
| `T_FIRST_CONTROL_IMMUNE` | 无 | 被施加控制类时 | 每次上场后第一次被施加的控制类状态无效，日志写“……人设生效，控制无效”；下场再上场重新计算 |
| `T_ENDURE` | 无 | 受到伤害时 | 每场对战一次：受到会让人气归零的伤害时，保留 1 点人气，日志写明；之后不再生效（下场也不重置） |
| `T_ALLY_PP_ON_ENTER` | `n` | 登场时 | 己方后排所有还在播的队友，每个技能 PP +n，不超过上限 |
| `T_STAGE_ON_HIT` | 能力名 → 等级，例如 `{"def": 1}` | 被击中后 | 受到伤害且没有下播时，按参数提升自身能力等级（上限 +6），每次被击中都触发 |
