# T-43 设置与本地存档模型

依赖：T-26（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
设置、档案、回放的读写统一到 Core 里一个地方，命令行和 Unity 都用它。只存本机，不上传，不收集个人信息。

## 要做的
1. 新文件 `Core/Save/GameSettings.cs`：`FastPlay, TurnTimer, Animations, AiLevel AiLevel, DefaultPack, Language, int Version`；`public const int CurrentVersion = 1`；`ToJson()`（键排序稳定）、`static FromJson(string)`（坏 JSON 返回默认值；缺字段用默认值；读入后 `Version` 升到当前）。默认：全部 false 除 `Animations = true`，`AiLevel.Normal`，`DefaultPack = "fan_asoul_vr"`，`Language = "zh-CN"`。
2. `public interface ISaveStore`，实现 `public sealed class FileSaveStore : ISaveStore`（构造参数为根目录，不存在时自动创建）：`SaveSettings/LoadSettings`、`SaveProfile/LoadProfile`、`SaveReplay(string name, string json)`（`replays/<name>.json`，最多 50 个，超出删最旧的；`name` 只允许字母数字、`_`、`-`，否则抛 `ArgumentException`）、`ListReplays()`（最新在前）、`LoadReplay(string name)`。所有路径必须在根目录内。
3. `Tools/Cli` 改用 `FileSaveStore`（`--save-dir`）。Unity 画面里的 `PlayerPrefs` 设置改为 `FileSaveStore(Application.persistentDataPath)`（只改读写调用）。
