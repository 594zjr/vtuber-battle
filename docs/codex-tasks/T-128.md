# T-128 联网对战使用完整赛制（多局、禁用、首发、修饰器）

依赖：T-54、T-29、T-63（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
T-54 的赛制（`Ruleset`、`Match`）现在只能本机用，联网只有单局休闲规则。让两台电脑也能按「排位」「乱斗」或自定义赛制打一整场三局两胜。

## 要做的
1. 联网握手时主机发送完整 `Ruleset` JSON 和 `Ruleset` 的内容指纹；客机校验（内容包、赛季、修饰器都存在）后确认，不一致时中文拒绝。这是协议变更：版本号按决定记录由审查员在合并时分配，写进 `docs/netplay-protocol.md` 并加固定样例；旧版本对端只能进休闲单局。
2. 一场多局比赛在同一连接里连续进行：每局开始前双方确认局号和该局种子（`Match` 的规则），每局结束双方校验终局哈希后上报比分；任一局不同步则整场判为不同步，不计排位。
3. 禁用和首发阶段沿用现有私密提交流程；计时按赛制配置创建 `TurnClock`。
4. 局域网房间广播（T-63）显示实际赛制名称和局数（只作显示，加入时仍以握手为准）。
5. `Tools/Cli` 允许 `--ruleset` 与 `--host`/`--join`/`--lan-host` 同用（解除 T-54 的限制）。
6. 排位分（T-57）只在整场比赛双方确认结束后按整场胜负结算一次。

## 验收
自带测试 `Engine.Tests/T128_NetRulesetTests.cs`（用 `LoopbackPair`）：三局两胜联网打完后双方比分和每局哈希一致；规则不一致被拒绝；中途一局不同步时整场不计分；旧协议对端回退到休闲单局；整场只结算一次排位分；修饰器在双方都生效。
