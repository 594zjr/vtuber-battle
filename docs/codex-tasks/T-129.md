# T-129 同屏双人对战使用赛制

依赖：T-54、T-86（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
同屏双人（T-86）现在只能打单局。接入 T-54 的赛制，让两个人在一台电脑上也能打三局两胜、带禁用和首发选择。

## 要做的
1. `HotseatSession` 接受 `Ruleset`：按 `Match` 逐局开局；禁用和首发阶段沿用同屏的私密交接流程（轮到谁时另一方不可见）。
2. 计时按赛制配置（与 T-111 的限时如已合并保持同一套逻辑，不重复实现）。
3. 局间显示当前比分；整场结束显示最终比分；每局独立保存录像，`--report` 生成整场汇总（复用 T-54 的汇总）。
4. `Tools/Cli` 允许 `--ruleset` 与同屏模式同用（解除 T-54 的限制）。
5. 同屏对局不计排位分。

## 验收
自带测试 `Engine.Tests/T129_HotseatRulesetTests.cs`：三局两胜同屏流程比分正确；禁用和首发阶段对方选择在交接前不可见；每局种子符合 `Match` 规则；不传赛制时与原单局行为逐字节一致；不累计排位分。
