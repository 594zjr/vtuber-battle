# T-89 本地小型赛事：循环赛与瑞士轮

依赖：T-56（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
朋友聚会时用一台电脑或局域网办一个小比赛：录入每个人的队伍码，自动排对阵、记比分、出排名。

## 要做的
1. 新文件 `Core/Tournament.cs`：`Tournament(ContentDb db, string format /* roundrobin|swiss */, int rounds = 0)`；`AddPlayer(string name, string teamCode)`（用 T-56 的队伍码，非法队伍拒绝并给中文原因）；`List<Pairing> NextRound()`；`ReportResult(Pairing p, int winnerSide /* -1 平局 */)`；`List<Standing> Standings()`（积分：胜 3 平 1 负 0；同分比对手分、再比直接对话、最后按报名顺序）。
2. 瑞士轮：默认轮数 = ceil(log2(人数))；尽量不重复对阵；奇数人数时轮空（记一胜，每人最多轮空一次）。循环赛：每两人对一次。
3. 整个赛事可以存成 JSON 并读回（`ToJson`/`FromJson`），中途关掉程序不丢进度。
4. `Tools/Cli` 加 `--tournament <文件>`：交互式录入结果，也可以 `--auto` 让电脑代打（用 `AiLevel.Normal`）。

## 验收
自带测试 `Engine.Tests/T89_TournamentTests.cs`：4 人和 5 人循环赛对阵数正确；7 人瑞士轮 3 轮内没有重复对阵、每人最多轮空一次；积分和排名规则正确；存档读回后继续排对阵结果一致；非法队伍码被拒绝。
