# T-116 从录像任意回合接手，继续和电脑对战

依赖：T-83、T-35（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
看录像时觉得「如果这里换个选择会怎样」，可以从该回合接手，自己操作一方、电脑操作另一方继续打下去。

## 要做的
1. 新文件 `Core/ReplayBranch.cs`：`ReplayBranch.Start(ContentDb db, Replay r, int turn, int humanSide, AiLevel level)` 用 T-83 的游标重放到该回合开始，返回一局可以继续进行的 `Battle`；从这一刻起用新的确定性种子（由原种子和回合号派生，写进 design.md），保证同样操作得到同样结果。
2. 新对局的录像记录「来自哪份录像的第几回合」，可以单独保存到录像库（T-80）；不修改原录像。
3. 这种对局不计入排位分和本机统计里的正式战绩（标记 `IsBranch`）。
4. `Tools/Cli` 加 `--branch <录像> --turn <回合> --side <0|1> [--ai normal|hard|expert]`。

## 验收
自带测试 `Engine.Tests/T116_ReplayBranchTests.cs`：从第 N 回合接手时双方血量、状态、直播间效果与原录像第 N 回合开始时一致；两次接手后做同样操作结果相同；新录像能独立回放且标明来源；原录像对象和文件不变；超出录像长度的回合号给出中文错误。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
