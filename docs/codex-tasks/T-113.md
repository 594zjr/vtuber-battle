# T-113 主播资料卡：从内容包生成可读的对战资料

依赖：T-76、T-22（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
玩家组队前想快速了解一位主播：赛道、六维数值、人设特性、四个技能和必杀、克制关系。由内容包数据直接生成，换包或改数值后自动更新。

## 要做的
1. 新文件 `Core/View/StreamerCard.cs`：`StreamerCard.Build(ContentDb db, string streamerId)` 返回结构化资料：名字、赛道（含 T-109 的符号）、六维数值和在本包内的排名、人设特性说明（复用 T-76 的规则说明文字）、每个技能的威力/命中/PP/先制/效果说明、被哪些赛道克制和克制哪些赛道。
2. `StreamerCard.ToText(...)` 生成中文纯文本；所有文字来自内容包和现有说明生成器，不手写任何角色设定，不加入任何内容包里没有的人物信息。
3. `Tools/Cli` 加 `--card <主播id>` 和 `--cards <包id>`（输出整包）。
4. 不改任何数值、规则和内容包文件。

## 验收
自带测试 `Engine.Tests/T113_StreamerCardTests.cs`：四个内容包每位主播都能生成资料卡且无空字段；技能数值与内容包一致；克制关系与 `StreamDuelRules.json` 一致；排名在同包内并列时处理正确；输出不含任何「（未知）」或占位字样。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
