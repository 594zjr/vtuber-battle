# T-76 规则说明数据：赛道克制、状态、直播间效果、人设

依赖：T-42（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
对战界面里「这是什么意思？」的说明数据。全部由内容包自动生成，换包也正确。（这是查阅用的说明，不是教学关卡。）

## 要做的
1. 新文件 `Core/View/Glossary.cs`：`public static List<GlossaryEntry> Build(ContentDb db)`；`GlossaryEntry { string Category, Id, Title, Text; List<string> Tags; }`。Category：`track`（赛道，Text 写克制谁、被谁克制、倍率）、`status`（控制/弱化，持续、能否消除、效果）、`field`（直播间效果：回合类/印记/保护，触发节点、能否消除）、`persona`（人设代码说明，用 `Describe`）、`rule`（结算顺序节点、先制、PP、能力等级上下限、换人规则——取自 design.md 的数值）。
2. `public static List<GlossaryEntry> Search(List<GlossaryEntry> all, string keyword)`：标题或文本包含关键字（不区分大小写）。
3. 文本走 `Loc`；不出现内部 id、英文代码名（例如 `T_KO_HEAL`）。
4. `Tools/Cli` 加 `--glossary [关键字]`。

## 验收
自带测试 `Engine.Tests/T76_GlossaryTests.cs`：四个内容包的每个赛道、状态、直播间效果、人设都有条目；没有空文本；文本里不含 `_` 和连续三个以上的大写英文字母；搜索能找到任意一个状态名。
