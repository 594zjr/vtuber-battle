# T-20 A-SOUL × VirtuaReal：每位主播独有的人设和招牌技能

依赖：T-19、T-21（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
`fan_asoul_vr` 现在 7 位主播都借用原创包的技能组。给每位主播一个**独有的人设**和一个**独有的第五技能（招牌技能）**，让他们玩起来有自己的味道。

## 要做的
1. 只改 `UnityProject/Assets/StreamDuel/Resources/Packs/fan_asoul_vr.json`（用 T-19 的包内 `skills`/`personas`，必要时 `fields`），不改引擎、不改规则文件。新 id 一律以 `av_` 开头。
2. 每位主播：一个 `av_` 人设（可用任何已有人设代码，包括 T-21 新增的 5 个，参数自己定），一个 `av_` 第五技能。四个普通技能可以保留现在的。
3. 文案方向（只用公开的、正面的东西）：
   - 贝拉：A-SOUL 队长、舞蹈担当 → 舞台、节奏、领舞一类意象。
   - 嘉然：粉丝名「嘉心糖」、元气甜系 → 应援、甜、元气。
   - 乃琳：温柔沉稳、照顾队友 → 守护、安心、照顾。
   - 七海Nana7mi：VirtuaReal 2 期、鲨鱼形象 → 鲨鱼、海、反咬。
   - 中单光一：VirtuaReal 2 期、游戏主播（名字里的“中单”）→ 对线、稳住、游戏操作。
   - 阿萨Aza：VirtuaReal 6 期 → 只用中性的直播意象（开播、陪伴、稳定输出），不要编造具体爱好。
   - 艾因Eine：VirtuaReal 1 期 → 前辈、可靠、元老之类中性意象，不要编造具体爱好。
4. **禁区**（任何一条违反都要改掉）：不写现实中的事件、争议、合同、毕业/休眠/退圈、数据或收入；不提中之人；不写恋爱、擦边、贬损、嘲讽或“梗”化的负面称呼；不出现其他主播或公司的名字；不用官方台词原文；技能名和描述都是我们自己的原创中文，不得用赛尔号（淘米）的任何名字或文本。拿不准的词就不用。

6. 平衡：用 `dotnet run --project Tools/Sim -- --pack fan_asoul_vr --games 5000 --seed 1`，每位主播胜率在 40%～60%。把结果写进 `docs/balance.md` 的 fan_asoul_vr 一节。
