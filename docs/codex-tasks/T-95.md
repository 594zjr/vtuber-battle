# T-95 电脑权重调优（自我对弈）

依赖：T-33（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
用自我对弈把 Normal、Hard 的打分权重调得更好，让电脑更像会玩的人。

## 要做的
1. 扩展 `Tools/Sim --tune`（T-33）：从当前权重出发，每轮随机扰动若干组权重（随机数来自固定种子），与当前最佳各打 400 局（对称阵容、交换先后手），胜率显著高于 52% 才替换；记录每轮结果。
2. 跑完后把 Normal 和 Hard 的新权重写进 `AiWeights` 的默认值；Easy 不变；Expert 若复用 Hard 权重则跟随。
3. 新文件 `docs/ai-tuning.md`：参数、轮数、每轮胜率、最终新旧对比（新 Hard 对旧 Hard 至少 500 局）。
4. 确认所有已有测试仍然通过（尤其电脑相关测试和难度顺序）；如果 T-85 已合并，同步更新 `docs/ai-baseline.json`。

## 验收
自带测试 `Engine.Tests/T95_TunedWeightsTests.cs`：新 Hard 对旧 Hard（旧权重写成测试里的常量）在固定种子 200 局里胜率 ≥ 52%；新 Normal 对旧 Normal 同样；Hard 仍然明显强于 Normal（≥ 55%）。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
