# T-09 画面改用 UI Toolkit + 头像图片（需要本机有 Unity）

依赖：T-08（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
把 IMGUI 画面换成 UI Toolkit（UXML + USS），为正式美术做准备。功能与 docs/design.md 第 8 节完全一致。

## 要做的
1. 新建 `Assets/StreamDuel/UI/`：`TeamScreen.uxml`、`BattleScreen.uxml`、`Theme.uss`，以及对应的控制脚本（放 `Game/`）。只调用 Core 的公开接口，不在画面层算任何规则。
2. 字体：放一份开源中文字体（思源黑体 / Noto Sans SC，SIL OFL 许可）到 `Assets/StreamDuel/Fonts/`，附带它的 `OFL.txt`；只放需要的字重。**不得使用来源不明或系统自带的商业字体文件。**
3. 头像：存在 `Resources/Portraits/<packId>/<streamerId>.png` 就显示图片，否则继续用程序生成的彩色圆形。仓库里**不放任何头像图片**（测试用的图验证完删掉）。
4. 第 8 节列出的每一项都要有：内容包切换、6 号位、主播卡、详情面板（每个效果标〔命中前/命中后判定〕和〔能否消除〕）、5 个技能按钮（第五技能金色）、可换人标记、结算顺序条、战斗记录逐行回放、快速播放、10 秒限时、结束弹窗、同人包常驻声明。
5. 功能全部迁移、截图确认后删除旧的 `BattleScreen.cs`，`GameBoot` 改为加载新画面。

## 验收
1280×720 和 1920×1080 下不重叠、不截字；截图覆盖上面每一项。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过。
2. 本机 Unity 打开工程 Console 无红色报错、无黄色警告，包括 T-08 暂留的「旧输入系统弃用」警告也要消除（改用新输入系统 Input System 包或 UI Toolkit 自带输入，并把 Player Settings 的 Active Input Handling 改为新系统）；按 Play 能完整打完一局。PR 里写 Unity 版本，附截图（存到 PR 评论或描述里，不要提交进仓库）。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
**本机没有安装 Unity 就不要领这个任务**（跳过它领下一个）。不要自己安装 Unity。
