# T-136 第三期原创主播的电脑专属出招风格

依赖：T-72、T-53（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
T-53 给前几期主播配了电脑专属出招风格。T-72 新增的十二位第三期原创主播还没有，电脑用它们时打法千篇一律。

## 要做的
1. 按 T-53 的方式（`AiStyles` 的数据格式）为第三期十二位主播各写一个风格：偏好的技能类型、开局习惯、低血量时的倾向，与其人设特性和技能组相符。
2. 风格只影响电脑选择的权重，不改任何数值和规则。
3. 用 `Tools/Ladder` 跑「有风格」对「无风格」各 300 局，胜率不下降超过 3 个百分点，结果写进 PR。

## 验收
自带测试 `Engine.Tests/T136_Pack3StyleTests.cs`：第三期每位主播都有风格且字段合法；同一局面同一种子选择结果确定；风格引用的技能都存在于该主播；没有风格的主播行为与原来一致。

完成标准：
1. 运行 `dotnet test Engine.Tests`，全部通过（包括原有的所有测试，不得修改原有测试的断言）。
2. 只改本任务列出的文件；需要改别的文件时在 PR 描述里说明原因。
3. 按 `.github/pull_request_template.md` 开 PR，标题以任务编号开头。
