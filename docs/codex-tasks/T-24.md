# T-24 状态哈希与行动编码（联网对战准备）

依赖：无（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
以后做联网对战时，双方各自跑同一个引擎、只交换行动；需要能检查两边状态是否一致。

## 要做的
1. `Battle.StateHash()`（新文件 `Core/Battle.Hash.cs`）：返回 `ulong`，用 FNV-1a 64 位，按固定顺序写入：回合数、阶段、双方 Active、每位主播的人气/是否下播/LastSkillIndex/各技能 id 与 PP/能力等级（按 `ContentDb.StatKeys` 顺序）/状态（id、剩余）/直播间效果（id、回合、层数）、Rng 内部状态、胜负。**不得**用 `string.GetHashCode` 或任何依赖进程的哈希。
2. `BattleAction.ToWire()` / `static BattleAction FromWire(string)`：技能 `S0`～`S4`，换人 `W0`～`W5`，跳过 `P`；格式不对抛 `FormatException`。
3. `Tools/Cli` 加 `--hash`：每回合结束打印一次哈希。
4. `docs/design.md` 末尾“以后”一节补一句联网对战的同步方式（只交换行动，每回合比对哈希）。
