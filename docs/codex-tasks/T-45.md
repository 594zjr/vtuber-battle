# T-45 每日挑战（规则层）

依赖：T-46（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
每天一个固定的挑战：所有人同一天拿到同样的阵容、同样的敌人、同样的特殊规则。

## 要做的
1. 新文件 `Core/DailyChallenge.cs`：`public static DailyChallenge For(ContentDb db, DateTime date)`，只用 `date.Year/Month/Day` 生成种子（`yyyyMMdd` 与包 id 的 FNV 哈希组合），用引擎的 `Rng`，**不得**用 `System.Random` 或当前时间。
2. 字段：`Date`（yyyy-MM-dd）、`PackId`、`Title`（例如“10 月 15 日 · 速攻之日”，标题后缀由修饰器决定）、`PlayerTeam`（6 位，合法）、`EnemyTeam`（6 位）、`AiLevel`（normal 或 hard）、`Modifiers`（1～2 个，来自 T-46）、`Seed`；`Start()` 返回已按这些设置创建好的 `Battle`；`ToJson()`。
3. 如果 T-39 已合并，阵容用 `TeamBuilder.Suggest` 生成；否则用种子随机挑选合法阵容。
4. `Tools/Cli` 加 `--daily [yyyy-MM-dd]`（默认今天，本机时间）。
