# T-58 观战数据流

依赖：T-29（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
别人可以观看一场正在进行的对战，带几回合延迟防止给选手通风报信。

## 要做的
1. 新文件 `Core/Net/Spectator.cs`：
   - `SpectatorFeed(Battle b, int delayTurns)`：`AddViewer(INetTransport t)`；`Pump()`：把对战记录里**已经比当前回合早 `delayTurns` 回合以上**的事件发给所有观众（第一次发送前先发开局信息：内容包 id、内容指纹（若 T-30 已合并）、种子、双方名字和队伍、选项）；`Finish()`：对战结束后发出剩余全部事件和结束标记。
   - `SpectatorClient(ContentDb db, INetTransport t)`：`Poll()` 收消息并用同一引擎重建对战（`Battle` 属性，开局信息到达前为 null）；内容包不一致或消息损坏时写 `Error`。
2. 消息格式与 T-29 一样是紧凑 JSON 行；行动用 `ToWire()`。
3. 如果 T-31 已合并：`Tools/Cli` 主机加 `--spectate-port <端口>` 允许观众连接，加 `--watch <地址:端口>` 观战。
