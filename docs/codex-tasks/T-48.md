# T-48 回放分享码

依赖：T-30（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。

## 目标
一局对战变成一串可以复制粘贴的文字，别人粘贴进游戏就能看回放。

## 要做的
1. 新文件 `Core/ShareCode.cs`：`public static string Encode(BattleRecord r)`、`public static BattleRecord Decode(string code)`。
   - 格式：`SD1-` + base64url（无填充）编码的 [记录 JSON 经 Deflate 压缩] + [4 字节 CRC32 或 FNV 校验]。只用 `System.IO.Compression`（.NET Standard 2.1 自带）。
   - 解码时忽略所有空白和换行；前缀不对、base64 坏、校验不符、解压失败、JSON 不合法都抛 `FormatException`（信息中文）。
   - 普通一局的分享码长度 < 1500 字符；如果超过，先把记录 JSON 换成更紧凑的写法（例如事件用短键），不要牺牲可读的旧格式（`ToJson` 不变，压缩前可以用单独的紧凑序列化）。
2. `Tools/Cli` 加 `--share`（结束后打印分享码）和 `--replay-code <码>`。
