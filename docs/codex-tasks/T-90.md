# T-90 电脑的禁用与首发选择更聪明

依赖：T-25、T-77（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
电脑在禁用阶段和首发选择时考虑双方阵容的对位，而不是简单规则。

## 要做的
1. `Ai.ChooseBan(b, s, level)`、`Ai.ChooseLead(b, s, level)` 增加按难度区分的策略（原来的无难度重载保持行为不变，或等价于 Normal）：
   - Easy：随机（来自 `Battle.Rng`）。
   - Normal：现有规则。
   - Hard/Expert：用 `DamageCalc.Matchup`（T-77）算对位表；禁用对方阵容里「对我方威胁总和最大」的主播；首发选「对对方可能首发的期望收益最大」的主播（Expert 额外考虑对方被禁用后的阵容）。
2. 不读取对方未公开的信息（首发选择时看不到对方的首发）；同样输入同样输出。
3. `Tools/Ladder` 跑 Hard 新策略对旧策略各 500 局，结果写进 PR（新策略胜率应 ≥ 50%）。

## 验收
自带测试 `Engine.Tests/T90_SmartBanLeadTests.cs`：Hard 在构造的明显局面（对方有一位克制我方 4 位以上的主播）里会禁用它；首发选择不依赖对方未公开的首发（交换对方首发不改变结果）；确定性；Easy 的选择合法。
