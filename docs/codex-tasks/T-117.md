# T-117 整局对战的性能剖析与热点优化

依赖：T-52（依赖的任务在 docs/TASKS.md 里标 ✅ 之后才能领）

先读仓库根目录的 AGENTS.md 和 docs/design.md，严格遵守其中的规则和禁止事项（Core 不得引用 UnityEngine、只用 C# 9、随机数只能来自 Battle 自带的 Rng、不得提交官方素材、不得出现赛尔号文本、不得修改 LICENSE、Packs/LICENSE.md、FANWORK.md 和 README 里的同人声明）。本游戏只做对战（玩家对玩家、玩家对电脑）。

## 目标
专家电脑、批量自我对弈和平衡检查都要跑很多局。找出引擎里最耗时、最耗内存的几处并优化，不改变任何结果。

## 要做的
1. `Tools/Bench`（T-52）增加整局基准：四个内容包、普通/困难/专家电脑各 200 局，输出每局平均耗时、每回合内存分配（`GC.GetAllocatedBytesForCurrentThread`）、`Battle.Clone` 次数。
2. 找出前三个热点（在 PR 里贴数据），做不改变行为的优化，例如减少克隆时的分配、缓存赛道克制表、避免日志字符串在不需要时拼接。
3. 优化前后用同一批种子跑完整对局，最终 `StateHash`、日志和录像必须逐字节相同；现有黄金录像全部通过。
4. 优化结果（前后对比表）写进 PR 和 design.md 的性能小节。

## 验收
自带测试 `Engine.Tests/T117_PerfInvariantTests.cs`：100 个固定种子的整局对战，优化后的 `StateHash` 和日志与测试里记录的基准值一致（基准值在优化前生成并写进测试）；`Battle.Clone` 后修改克隆不影响原局。PR 里给出耗时或分配至少一项下降 20% 的数据。
